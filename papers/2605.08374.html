MemQ: Integrating Q-Learning into Self-Evolving Memory Agents over Provenance DAGs

详细解读

论文核心总结

MemQ 这篇论文解决的是 LLM 智能体（Agent）在使用外部情景记忆（episodic memory）时的多步信用分配（multi-step credit assignment）问题。现有方法在评估每条记忆的价值时都是独立的——只看这条记忆被检索后当前任务的成败，而忽略了记忆之间存在的依赖链：一条早期记忆可能间接促成了后续记忆的产生，并最终导致下游任务的成功。MemQ 通过构建一个溯源有向无环图（Provenance DAG）来记录每条新记忆是由哪些被检索的旧记忆所"催生"的，然后利用 $\text{TD}(\lambda)$ 资格迹（eligibility traces）沿着这个 DAG 反向传播信用，使得祖先记忆也能获得来自下游成功的反馈。论文将这一设定形式化为外生上下文马尔可夫决策过程（Exogenous-Context MDP, EC-MDP），将状态分解为智能体无法控制的外生任务流和智能体可以影响的内生记忆库。在六个基准测试上，MemQ 在泛化评估和运行时学习中均取得了最高成功率。

1. 研究动机与问题定义

1.1 背景：LLM 智能体的情景记忆

大语言模型（LLM）部署为智能体后，如果不进行昂贵的权重更新，就无法适应新任务或变化的环境。一种越来越流行的做法是给智能体配备外部情景记忆库：智能体在执行任务的过程中，将成功经验、失败教训和发现的策略记录下来，存入一个向量数据库；在面对新任务时，从中检索相关记忆来辅助决策。
现有方法的检索通常依赖固定的启发式评分，最典型的就是嵌入向量的余弦相似度——哪条记忆和当前任务最相似就检索哪条。这种方式没有来自任务结果的学习信号，无法根据经验调整哪些记忆真正有价值。

1.2 已有的 RL 方法及其局限

最近的工作 MemRL 开始用强化学习来学习记忆的价值：它给每条记忆附加一个 Q 值，用单步指数移动平均（EMA）来更新，本质上是把检索建模为一个 $\gamma = 0$ 的上下文赌博机（contextual bandit）。这意味着每条记忆只根据它被检索时那一次任务的即时奖励来更新 Q 值。

1.3 核心问题：多步信用分配

论文指出，记忆之间并不是独立的。当一组记忆被检索用于某个任务时，任务的执行轨迹会产生一条新记忆，这条新记忆将来又可能被检索用于另一个任务，产生更新的记忆，形成链式依赖：

$\displaystyle m_a \to m_b \to m_c \to r$

在这个链条中，记忆 $m_a$ 通过促成中间记忆 $m_b$ 的产生，间接地对最终奖励 $r$ 做出了贡献。但在单步更新下，$m_a$ 完全无法从下游的成功中获得任何反馈——它的 Q 值停滞不前，而 $m_b$ 却不断积累信用。
这恰好是资格迹（eligibility traces）擅长处理的场景：当奖励稀疏且因果链较长时，跨多步传播信用比单步更新能产生更快、更准确的价值估计。然而，此前没有任何工作将基于迹的信用分配应用于情景记忆管理。

2. 形式化框架：外生上下文 MDP（EC-MDP）

2.1 状态的分解

论文观察到，这个设定中的状态天然地分解为两个具有根本不同动力学的组成部分：

  • 外生任务流（exogenous task stream）：任务 $s_t$ 从某个未知分布 $\rho$ 中独立采样，智能体无法影响下一个任务是什么。
  • 内生记忆库（endogenous memory store）：记忆库 $\mathcal{M}_t$ 的演化完全由智能体的检索动作和冻结 LLM 的响应决定。

2.2 EC-MDP 的定义

定义 1（Exogenous-Context MDP）：EC-MDP 是一个元组 $\langle \mathcal{S}, \mathcal{M}, \mathcal{A}, P_{\text{exo}}, P_{\text{endo}}, R, \gamma \rangle$，其中：

  • $\mathcal{S}$ 是外生状态空间（所有任务的集合），其演化由 $P_{\text{exo}}(s_{t+1}) = \rho(s_{t+1})$ 控制，独立于智能体的动作或记忆。
  • $\mathcal{M} \subseteq 2^{\mathcal{M}_\infty}$ 是内生状态空间（记忆库）。
  • $\mathcal{A}(\mathcal{M}) = \{A \subseteq \mathcal{M} : |A| \leq k\}$ 是动作空间，即从记忆库中选取至多 $k$ 条记忆的子集。
  • $P_{\text{endo}}(\mathcal{M}_{t+1} | s_t, \mathcal{M}_t, A_t)$ 是内生转移核，它吸收了冻结 LLM 的行为：

$\displaystyle P_{\text{endo}}(\mathcal{M}_{t+1} | s_t, \mathcal{M}_t, A_t) = \sum_{\tau} \pi_{\text{LLM}}(\tau | s_t, A_t) \cdot \mathbf{1}[\mathcal{M}_{t+1} = \mathcal{M}_t \cup \{\text{Build}(s_t, \tau)\}]$ - $R(s_t, A_t) = \mathbb{E}_{\tau \sim \pi_{\text{LLM}}(\cdot|s_t, A_t)}[r(\tau)]$ 是奖励。 - $\gamma \in [0, 1]$ 是折扣因子。
EC-MDP 的核心特征是联合转移核可以分解：

$\displaystyle P(s_{t+1}, \mathcal{M}_{t+1} | s_t, \mathcal{M}_t, A_t) = P_{\text{exo}}(s_{t+1}) \cdot P_{\text{endo}}(\mathcal{M}_{t+1} | s_t, \mathcal{M}_t, A_t)$

这意味着下一个任务 $s_{t+1}$ 与当前的状态和动作完全无关。此外，由于记忆库是单调增长的（$\mathcal{M}_{t+1} \supseteq \mathcal{M}_t$），过程满足马尔可夫性质。
这个分解还保证了一个重要的条件独立性：奖励 $r_t$ 和新构建的记忆 $m_{\text{new}}$ 只依赖于当前任务和被检索的集合，与未被检索的记忆无关：

$\displaystyle P(r_t, m_{\text{new}} | s_t, \mathcal{M}_t, A_t) = P(r_t, m_{\text{new}} | s_t, A_t)$

2.3 价值函数与学习目标

状态价值函数捕捉记忆库的长期价值：

$\displaystyle V^{\pi_{\text{ret}}}(\mathcal{M}_t) = \mathbb{E}_{s_k \sim \rho, A_k \sim \pi_{\text{ret}}, \tau_k \sim \pi_{\text{LLM}}} \left[\sum_{k=0}^{\infty} \gamma^k r(\tau_{t+k}) \;\middle|\; \mathcal{M}_t \right]$

学习目标是最大化初始记忆库的价值：$\max_{\pi_{\text{ret}}} V^{\pi_{\text{ret}}}(\mathcal{M}_0)$。
为了绕过指数级的组合动作空间 $2^{\mathcal{M}}$，论文假设被检索的记忆独立贡献，用一阶分解来近似集合级别的价值：

$\displaystyle Q(s, A; \mathcal{M}) \approx \frac{1}{|A|} \sum_{m_i \in A} Q(m_i), \quad A \sim \pi_{\text{ret}}(\cdot | s, \mathcal{M})$

这里每个标量 $Q(m) \in \mathbb{R}$ 捕捉的是一个溯源价值：该记忆沿因果生成链对未来奖励的边际贡献。$Q(m)$ 满足一个结构性贝尔曼方程：

$\displaystyle Q(m) = \mathbb{E}_{s, A \ni m, \tau}\left[r(\tau) + \gamma \, Q(m_{\text{new}}) \;\middle|\; m \in A\right]$

其中 $m_{\text{new}} = \text{Build}(s, \tau)$。关键的替换是：用下游记忆的价值 $\gamma Q(m_{\text{new}})$ 替代了时间上的自举项 $\gamma V^{\pi_{\text{ret}}}(\mathcal{M}')$。

3. MemQ 方法

MemQ 方法分为三个部分：Q 值增强的记忆存储、两阶段检索策略、以及通过溯源 DAG 的信用传播。

3.1 Q 值增强的程序化记忆构建

记忆库 $\mathcal{M} = \{m_1, m_2, \ldots, m_N\}$ 中的每条记忆是一个三元组：

$\displaystyle m_i = (c_i, \mathbf{e}_i, Q_i)$

  • $c_i$：记忆内容（自然语言文本）
  • $\mathbf{e}_i = \phi(c_i) \in \mathbb{R}^d$：由冻结编码器计算的嵌入向量
  • $Q_i \in \mathbb{R}$：Q 值，即该记忆被检索时的价值估计
    每次与环境交互后，系统基于采样的轨迹构建新记忆。记忆构建器采用程序化（proceduralization）方式：LLM 将轨迹 $\tau$ 蒸馏为一个 3-5 步的抽象脚本，同时保存脚本和原始轨迹作为记忆内容。成功的轨迹直接存储；失败时，LLM 生成一个反思（reflection）——分析哪里出了问题——作为单独的记忆存储。
    新记忆的初始 Q 值设为其"父记忆"（即创建它时被检索的那些记忆）的 Q 值平均：

$\displaystyle Q(m_{\text{new}}) = \frac{1}{|A_j|} \sum_{m_i \in A_j} Q(m_i)$

当没有检索到任何记忆时（$A_j = \emptyset$），$Q(m_{\text{new}})$ 随机初始化。

3.2 带局部一致性的 Q 值引导检索策略

检索策略分为两个阶段：
阶段一：局部性过滤（Locality Filtering）
这基于 LLM 的局部一致性（local consistency）性质：如果检索到的记忆与当前任务的距离在某个"能力半径"$r$ 之内，LLM 的最优性差距 $\varepsilon_{\text{LLM}}(r)$ 就很小。具体实现是用嵌入空间中的余弦相似度：

$\displaystyle \text{sim}(s, m_i) = \frac{\phi(s)^\top \mathbf{e}_i}{\|\phi(s)\| \cdot \|\mathbf{e}_i\|}$

候选集为 $\mathcal{C}_s = \{m_i \in \mathcal{M} : \text{sim}(s, m_i) \geq \theta_{\text{sim}}\}$。如果没有记忆满足阈值，任务被视为全新的，智能体退回到零样本模式。
阶段二：Q 值引导选择（Q-guided Selection）
在局部性过滤保证所有候选都在 LLM 的能力半径内之后，用一个组合评分函数来区分它们：

$\displaystyle \text{score}(s, m_i) = w_s \cdot \text{sim}(s, m_i) + w_q \cdot Q(m_i)$

其中 $w_s$ 和 $w_q$ 控制相关性和学习价值之间的权衡。相似度分数和 Q 值都被归一化到 $[0, 1]$。
选择采用 $\varepsilon$-贪心策略：

$\displaystyle A = \begin{cases} \text{Top-}k \text{ by } \text{score}(s, m_i) & \text{以概率 } 1 - \varepsilon \\ \text{从 } \mathcal{C}_s \text{ 中均匀采样 } k \text{ 条} & \text{以概率 } \varepsilon \end{cases}$

3.3 基于溯源 DAG 的信用分配

这是 MemQ 的核心创新。
经典 $\text{TD}(\lambda)$ 的回顾：在经典 $\text{TD}(\lambda)$ 中，$\lambda$-回报的优势可以表示为未来 TD 误差的折扣和：

$\displaystyle G_t^\lambda - Q(s_t, a_t) = \sum_{k=0}^{T-t-1} (\gamma\lambda)^k \delta_{t+k}$

其中 $\delta_t = r_t + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)$。这个分解是资格迹的基础：通过 $(\gamma\lambda)^k$ 的权重，将时间步 $t+k$ 处的 TD 误差传播回时间步 $t$。
MemQ 的适配：MemQ 将这个原理从时间链适配到溯源 DAG——信用沿 DAG 的边反向流动，结构深度 $d$ 替代了时间步 $k$。
每条记忆的 TD 误差：对于任务 $s_j$，检索集 $A_j$，结果 $R_j$，和构建的新记忆 $m_{\text{new},j}$：

$\displaystyle \delta(m_i, j) = R_j + \gamma \, Q(m_{\text{new},j}) - Q(m_i), \quad \forall \, m_i \in A_j$

当 $\gamma = 0$ 时，自举项 $\gamma Q(m_{\text{new}})$ 消失，退化为单步 EMA 更新（即 MemRL 的做法）。
通过溯源 DAG 的信用传播：单步更新只更新直接被检索的记忆。为了传播信用到祖先，MemQ 利用溯源 DAG（记录了 $\text{parents}(m_{\text{new}}) = A$）。对于每个任务 $s_j$，先计算每个直接被检索的记忆 $m_0 \in A_j$ 的 TD 误差 $\delta(m_0, j)$，然后从 $m_0$ 出发做 BFS 反向遍历，传播到所有可达的祖先：

$\displaystyle \Delta Q(m) \mathrel{+}= \alpha \sum_{m_0 \in A_j} (\gamma\lambda)^{d(m, m_0)} \cdot \delta(m_0, j)$

其中 $d(m, m_0)$ 是从 $m_0$ 到 $m$ 在 DAG 中的最短路径长度。结构折扣 $(\gamma\lambda)^d$ 直接对应经典公式中的 $(\gamma\lambda)^k$，只是用 DAG 深度 $d$ 替代了时间步 $k$。
BFS 受最大深度 $D$ 和折扣下限 $(\gamma\lambda)^d < 10^{-12}$ 的约束。更新在每个训练 epoch 内累积在缓冲区中，连同更新计数 $N_i$。在 epoch 边界处刷新：

$\displaystyle Q(m_i) \leftarrow Q(m_i) + \text{clip}\left(\frac{\Delta Q(m_i)}{N_i}, -\epsilon_{\text{clip}}, \epsilon_{\text{clip}}\right)$

除以 $N_i$ 是为了归一化检索频率（类似批量梯度下降中的平均），延迟写入确保每个 epoch 内检索景观的稳定性。

4. 实验

4.1 实验设置

六个基准测试：

  1. LifeLongAgentBench (LLAB)：多步 OS 级别的智能体规划
  2. BFCL v3：多轮函数调用和错误恢复
  3. LiveCodeBench v6：竞赛级代码生成
  4. MMMU Pro：10 选 1 的多模态推理
  5. ERQA：多模态、物理常识问答
  6. GPQA Diamond：研究生级别的科学问答

六个基线方法：

  • No Memory：无记忆的冻结 LLM
  • RAG：用余弦相似度检索 top-k 记忆
  • Self-RAG：生成查询并通过自评估过滤无用记忆
  • Mem0：通过提取、更新、删除管理记忆生命周期
  • MemP：将轨迹蒸馏为程序化记忆
  • MemRL：用单步 EMA 更新每条记忆的 Q 值（$\gamma = 0$）

4.2 主要结果

泛化评估（在留出的测试集上）：MemQ 在六个基准中的五个上取得最高成功率，在 GPQA 上与 MemRL 持平（但方差更低）。关键发现：

  • MemQ 相比 MemRL 的优势在溯源链较深的任务上最大：LiveCodeBench +5.7 pp，ERQA +4.6 pp，BFCL +2.3 pp。
  • 在只需要浅层单步更新的任务上，差距缩小：GPQA 上两者都是 60.8%，MMMU Pro 上 MemQ 仅领先 0.77 pp。
    这证实了结构性信用分配的收益与任务复杂度成正比。

运行时学习（在训练集上）：MemQ 在全部六个基准上均取得最高成功率。在 ERQA 上，累积成功率（CSR）的差距尤其显著（+5.9 pp），表明记忆溯源信用不仅改善最终性能，还在整个训练过程中产生复合效应。

4.3 $\gamma$ 和 $\lambda$ 的深入分析

$\gamma$ 的作用——信任结构：
$\gamma$ 同时影响自举目标 $\gamma Q(m_{\text{new}})$ 和结构折扣 $(\gamma\lambda)^d$。实验揭示了一个跨基准的反转现象：

  • LiveCodeBench（单轮任务）在中等 $\gamma \approx 0.5$ 时达到峰值，$\gamma = 0.9$ 时急剧下降（~63% vs ~56%）
  • BFCL（多轮任务）偏好更高的 $\gamma \in [0.8, 1.0]$（~76% vs $\gamma=0$ 时的 ~73%）
    这反映了任务结构：BFCL 的多轮性质创建了深层溯源链，需要更大的 $\gamma$ 来跨整个 DAG 传播信用。而在单轮任务中，过大的 $\gamma$ 会放大来自远距离祖先的噪声。

$\lambda$ 的作用——不信任噪声：
$\lambda$ 控制 TD 误差沿 DAG 反向传播的衰减。在 LiveCodeBench 上（$\gamma = 0.3$），较低的 $\lambda = 0.3$ 表现最好（~~65.8%），而 $\lambda = 0.9$ 表现最差（~~59.5%）。
这个最优 $\lambda^\*$ 相对于标准 MDP 的下移，与 EC-MDP 的分解转移一致：因为下一个任务 $s_{t+1} \sim P_{\text{exo}}$ 独立于当前检索动作，跨任务边界传播信用引入的是纯方差而没有因果信号。因此，虽然经典的 $\text{TD}(\lambda)$ 偏差-方差权衡仍然成立，但外生任务流膨胀了方差，将 U 形最优点向左移动。
总结：$\gamma$ 和 $\lambda$ 的交互反映了 EC-MDP 的核心前提——因为内生记忆演化本质上是马尔可夫的，MemQ 用高 $\gamma$ 自信地沿因果溯源 DAG 分配结构性信用；但因为外生任务是独立采样的，跨任务转移引入纯方差，MemQ 用相对低的 $\lambda$ 来隔离结构性信用分配与无关任务的经验噪声。

5. 局限性

  1. 存储和计算开销：维护溯源 DAG 需要持续存储，BFS 信用传播每个任务的代价为 $O(|A_j| \cdot D)$。扩展到终身学习可能需要近似传播机制。
  2. 单调记忆增长：MemQ 假设记忆只增不减，没有显式处理记忆合并或删除。
  3. 局部性过滤依赖余弦相似度：探索替代距离度量可能进一步改善效果。
  4. 任务独立性假设：EC-MDP 假设任务状态从外部分布独立采样。如果智能体能影响任务序列（如主动课程学习），需要重新审视状态分解。

原文摘要

Episodic memory allows LLM agents to accumulate and retrieve experience, but current methods treat each memory independently, i.e., evaluating retrieval quality in isolation without accounting for the dependency chains through which memories enable the creation of future memories. We introduce MemQ, which applies TD($\lambda$) eligibility traces to memory Q-values, propagating credit backward through a provenance DAG that records which memories were retrieved when each new memory was created. Credit weight decays as $(\gamma\lambda)^d$ with DAG depth $d$, replacing temporal distance with structural proximity. We formalize the setting as an Exogenous-Context MDP, whose factored transition decouples the exogenous task stream from the endogenous memory store. Across six benchmarks, spanning OS interaction, function calling, code generation, multimodal reasoning, embodied reasoning, and expert-level QA, MemQ achieves the highest success rate on all six in generalization evaluation and runtime learning, with gains largest on multi-step tasks that produce deep and relevant provenance chains (up to +5.7~pp) and smallest on single-step classification (+0.77~pp) where single-step updates already suffice. We further study how $\gamma$ and $\lambda$ interact with the EC-MDP structure, providing principled guidance for parameter selection and future research. Code is available at this https URL .
