Memory in the Age of AI Agents

核心机制

以形式、功能和动态三个可组合维度组织 Agent Memory：从事实、经验与工作记忆，连接记忆形成、演化和检索。

适用范围与局限

分类框架用于定位研究，不构成方法性能排序；潜在表示不可读不等于隐私保证，处理长序列也不等于无限信息容量。具体方法的效果与保证仍需结合原论文条件。

详细解读

这篇综述论文系统地梳理了基于大语言模型（LLM）的AI智能体（Agent）的记忆系统研究，提出了一个统一的"形式—功能—动态"三维分类框架：从形式上将记忆分为Token级、参数级和潜在表示三类；从功能上区分事实记忆、经验记忆和工作记忆；从动态上分析记忆的形成、演化和检索三个过程，并对当前领域的碎片化现状进行了全面的梳理与整合，同时指出了多模态记忆、强化学习与记忆结合、多智能体共享记忆等前沿方向。

一、背景与动机

为什么记忆对AI智能体至关重要？

大语言模型（LLM）本质上是"无状态的条件生成器"——每次推理时只能看到当前上下文窗口内的内容，没有跨对话、跨任务的持久记忆。但真正有用的AI智能体（Agent）需要：

  • 在长期交互中保持一致性（比如记住用户偏好）
  • 从过去的成功和失败中学习，持续进化
  • 在复杂长任务中维持对目标和中间状态的追踪

因此，记忆机制是将静态LLM转变为动态、自适应智能体的核心要素。

现有分类的问题

过去的研究常用"长期记忆/短期记忆"来分类，但这种框架已经跟不上技术发展的步伐。2025年涌现的大量新方法——比如把过往经验提炼成可复用工具的记忆框架、与测试时扩展（test-time scaling）结合的记忆方法——都无法被旧分类体系很好地描述。加之"情景记忆""语义记忆""参数记忆"等术语在不同文献中含义混乱，这篇论文因此提出了一套全新的、更精细的分类体系。

二、基本概念的形式化定义

2.1 LLM智能体系统

论文把智能体系统形式化为：在时间步 $t$，环境状态 $s_t$ 按照转移模型 $s_{t+1} \sim \Psi(s_{t+1} | s_t, a_t)$ 演进，智能体 $i$ 观察到：

$$o_i^t = O_i(s_t, h_i^t, Q)$$

其中 $h_i^t$ 是该智能体可见的历史，$Q$ 是任务说明。智能体的决策策略为：

$$a_t = \pi_i(o_i^t, m_i^t, Q)$$

$m_i^t$ 是从记忆系统中检索出的记忆信号，这个信号正是记忆系统的核心输出。

2.2 记忆系统的生命周期

记忆系统被抽象为一个随时间演化的状态 $M_t$，其动态由三个算子刻画：

记忆形成（Memory Formation）：

$$M_{t+1}^{\text{form}} = F(M_t, \phi_t)$$

将智能体当前步产生的信息 $\phi_t$（工具输出、推理轨迹、环境反馈等）有选择地转化为记忆候选项。

记忆演化（Memory Evolution）：

$$M_{t+1} = E(M_{t+1}^{\text{form}})$$

将新形成的记忆整合进已有记忆库，可能进行合并、去冲突、剪枝等操作。

记忆检索（Memory Retrieval）：

$$m_i^t = R(M_t, o_i^t, Q)$$

根据当前观察和任务，从记忆库中检索相关内容，供智能体决策使用。

值得注意的是，"长期记忆"和"短期记忆"的区别并非来自两个分离的架构模块，而是来自上述三个算子被调用的时间模式——在任务内部频繁调用就是短期记忆效果，跨任务持久保存就是长期记忆效果。

2.3 智能体记忆 vs. 相关概念

论文花了相当篇幅区分容易混淆的几个概念：

  • 智能体记忆 vs. LLM记忆：KV 缓存和注意力机制主要涉及模型内部的上下文处理，而 Agent Memory 更强调记忆如何参与智能体的持续决策。不能简单按“内部/外部”或“是否跨任务”划线：本综述同时讨论 Token、参数和潜在表示，参数知识也可能持久存在。
  • 智能体记忆 vs. RAG：采用预建文档库的经典 RAG 设置侧重检索支撑回答，Agent Memory 更强调持续交互中的记忆形成、演化和调用。RAG 也可以使用动态知识库，两者并非互斥；评测数据集能提示任务重点，但不是定义边界。
  • 智能体记忆 vs. 上下文工程（Context Engineering）：上下文工程把上下文窗口当作有限计算资源来优化（指令格式化、工具调用调度等），是接口层的资源管理；智能体记忆则是认知层的持久状态，管理的是智能体"知道什么、经历过什么"，范围远超单个上下文窗口。

三、形式（Form）：记忆存储在哪里？

这是论文分类框架的第一个维度：记忆以什么形式被承载？

3.1 Token级记忆（Token-level Memory）

这是最直观也是研究最多的记忆形式：记忆以离散的、可读的、可编辑的文本单元（或视觉/音频token）存储在模型外部，可以被直接检索、修改和调试。

论文按照存储单元之间的拓扑结构，将Token级记忆分为三类：

3.1.1 平坦记忆（Flat Memory，1D）

单元之间没有显式的语义或关系连接，就像一个列表或集合。

典型内容包括：

  • 对话历史：最直接的形式，MemGPT把它类比成操作系统的虚拟内存，设计了主存（上下文窗口）和外存（数据库）的分层管理。Mem0建立了标准化的记忆增删改查操作。
  • 用户画像：MemoryBank存储带时间戳的对话历史和用户个人信息；RoleLLM则把角色特定的知识压缩成问答对。
  • 经验轨迹：Reflexion把过去的反馈作为长期记忆，把当前轨迹作为短期记忆；ExpeL从成功/失败案例中自动提取洞见。
  • 多模态条目：MovieChat维护视频帧的短期/长期记忆；KARMA在具身场景中用3D场景图存储长期记忆、用目标状态变化存储短期记忆。

优点：简单、可扩展，易于增删，相似度搜索可灵活访问。
缺点：缺乏结构，随记忆增长，冗余和噪声累积；检索到的单元之间的关系不清晰，不利于组合推理。

3.1.2 平面记忆（Planar Memory，2D）

在单一层面内引入了显式的拓扑关系（图、树、表格），能够捕捉记忆单元之间的关联、因果和时间关系。

  • 树结构：HAT把长对话分段后逐级聚合成层次树，支持从粗到细的检索；MemTree动态推断对话日志的层次结构，把具体事件逐步汇总成更高层概念。
  • 图结构：这是平面记忆中最主流的形式。Ret-LLM把外部记忆抽象成可寻址的三元组（主语-谓语-宾语）；A-MEM把知识标准化为"卡片"式单元，按相关性链接成记忆网络；M3-Agent把图像、音频、文本统一成以实体为中心的记忆图。

优点：通过节点间链接捕捉更丰富的上下文，支持结构化检索（键值查找、图遍历）。
缺点：没有层次存储机制，所有记忆都压缩在单一平面，随任务复杂性增加会显得力不从心；构建和搜索成本较高。

3.1.3 层次记忆（Hierarchical Memory，3D）

跨多个抽象层次组织信息，形成"体积式"记忆空间，可以在层内横向关联也可以跨层纵向抽象。

  • 金字塔结构：HiAgent维护以子目标为中心的层次工作记忆，当前活跃子目标保留详细轨迹，已完成子目标压缩为高层摘要；GraphRAG通过社区检测算法在实体子图上递归聚合，形成从实体到社区的多层摘要。
  • 多层结构：HippoRAG受海马体启发，将记忆分为联想索引（开放知识图谱）和底层段落存储两层；AriGraph在统一图中分离语义知识图（世界模型）和事件级组件（具体观察）；SGMem在原始对话之上增加一个句子图层次。

优点：不同抽象层次的记忆可以互动，支持复杂多路径查询，兼具精度和全面性。
缺点：结构复杂，如何确保所有存储记忆的语义有效性、如何设计最优三维布局，都是尚待解决的难题。

3.2 参数级记忆（Parametric Memory）

信息直接编码在模型参数中，通过前向计算隐式访问，不依赖外部存储。分为：

3.2.1 内部参数记忆

信息编码在原始模型权重中，通过不同阶段的训练注入：

  • 预训练阶段：LMLM和HierMemLM在预训练时就把知识检索能力内置入模型，知识本身存在外部库，但检索先验被编码进权重。StreamingLLM等通过优化注意力机制提升长窗口记忆能力。
  • 中间训练阶段：将可泛化的经验（如Agent交互轨迹）通过持续预训练注入模型，代表工作有Early Experience。
  • 后训练阶段：Character-LM、CharacterGLM等通过SFT让模型学会特定角色风格；KnowledgeEditor、MEND等专注于知识编辑，在不影响其他知识的前提下精准修改特定事实；Room用RL让模型内化具身任务经验。

优点：无额外推理开销，适合大规模领域知识或任务先验的存储。
缺点：更新困难，需要重新训练，容易遗忘旧知识；不适合短期个性化记忆。

3.2.2 外部参数记忆

在冻结的基础模型之外引入额外的可训练模块（如适配器、LoRA）来承载记忆，是一种折中方案。

  • 适配器类：K-Adapter通过独立训练的任务特定适配器注入新知识，不干扰原始预训练表示；WISE维护双参数内存（预训练知识 + 编辑知识），用路由机制动态选择；MemLoRA用LoRA来存储和检索记忆。
  • 辅助语言模型类：MAC用摊销网络把新文档信息压缩为紧凑调制，存入记忆库；Retroformer专门学习记忆过去任务成功/失败经验的范式。

3.3 潜在记忆（Latent Memory）

记忆隐含在模型内部的连续表示中（KV缓存、激活、隐藏状态、潜在嵌入），而非可读文本或独立参数集。论文按潜在状态的来源分为三类：

3.3.1 生成式（Generate）

通过专门的编码器或辅助模块主动生成紧凑的潜在表示作为记忆单元：

  • Gist：训练语言模型在处理长提示后生成一组"要旨token"。
  • AutoCompressor：把整篇长文档编码成少量摘要向量，作为软提示重用。
  • MemoryLLM：在模型潜在空间中嵌入专用记忆token，形成可持久更新的记忆。
  • Titans：将长程信息压缩进在线更新的MLP权重，在推理时动态产生潜在向量。

多模态场景下（CoMem、XMem等），将图像、视频帧等压缩为连续嵌入。

3.3.2 复用式（Reuse）

直接将过去推理的KV缓存作为记忆重用，不加任何修改：

  • Memorizing Transformers：显式存储历史KV对，通过K近邻搜索检索。
  • FOT（Focused Transformer）：在标准注意力之外加入记忆注意力层，对额外KV记忆做KNN检索。
  • LONGMEM：用轻量级残差侧网络把历史KV嵌入作为持久记忆。

优点：完全保真，无信息损失，实现简单。
缺点：KV缓存随上下文长度快速增长，索引效率依赖于检索策略的设计。

3.3.3 变换式（Transform）

对已有的KV缓存或隐藏激活进行压缩、选择或重构，而不是生成全新表示：

  • Scissorhands：基于注意力分数剪枝token。
  • SnapKV：通过头级投票机制聚合高重要度前缀KV表示。
  • PyramidKV：按层分配不同的KV预算。
  • H2O：保留"重击"token（heavy hitter）和最近token，减少内存占用。

3.4 三种形式的适用场景对比

记忆形式 主要特征 典型适用场景
Token级 符号化、可寻址、透明、易于增删改 多轮对话、个性化agent、推荐系统、高风险领域（法律、医疗）
参数级 隐式、抽象、可泛化，更新较慢 角色扮演、推理密集任务、人类价值对齐
潜在级 机器原生、对齐模型内部计算、支持多模态 多模态agent、边缘端部署、隐私敏感场景

四、功能（Function）：为什么智能体需要记忆？

这一维度问的是记忆服务于什么目的。论文提出三大功能支柱：

4.1 事实记忆（Factual Memory）

事实记忆存储和检索与用户、环境相关的声明性事实，回答"智能体知道什么"。

对应认知科学中的陈述性记忆（declarative memory），进一步区分两个子类：

4.1.1 用户事实记忆

跨会话持久化关于特定用户的可验证事实（身份、偏好、历史承诺、惯常习惯）。核心功能是防止无状态交互的典型失败模式：重复提问、前后矛盾、主题漂移。

两类主要机制：

  • 对话连贯性：通过排名检索（按相关性、时效性、重要性筛选）和语义抽象（把原始对话片段转化为高层表示），维护跨轮次的一致性。例如Think-in-Memory把对话转化为"思考"表示；COMEDY用单一模型生成、压缩、复用记忆并更新紧凑用户画像。
  • 目标一致性：跟踪并更新任务状态，确保智能体的行动始终与主目标对齐，防止意图漂移。RecurrentGPT在保留已确认信息的同时突出未解决要素。
4.1.2 环境事实记忆

记录与外部世界（文档、代码库、工具能力、其他智能体状态）相关的事实。分为：

  • 知识持久化：在多会话中维护对外部知识的可访问性。HippoRAG用知识图谱支持证据传播；MemoryLLM直接把可训练记忆池嵌入模型架构，支持在不重训的情况下动态注入新知识。
  • 多智能体共享访问：建立多智能体协作的公共事实基础，消除重复劳动、避免矛盾结论。MetaGPT使用共享消息池作为中央工作空间；Generative Agents（斯坦福"小镇"实验）把全局环境和公共交互日志作为所有智能体的共享记忆。

4.2 经验记忆（Experiential Memory）

经验记忆积累历史轨迹、提炼策略、内化交互结果，回答"智能体如何进化"。对应认知科学中的程序性记忆（procedural memory）。

与生物程序性记忆不同，智能体的经验记忆通常以显式数据结构存储，因此可以被自省、编辑和推理——这是AI相比人类的独特优势。

按存储知识的抽象层次，分为四类：

4.2.1 基于案例的记忆（Case-based Memory）

存储最小处理的历史事件记录，优先保持高保真度，支持直接回放或作为上下文示例。

  • 轨迹：保存完整的交互序列。Memento用软Q-learning动态调整选择高价值历史轨迹的概率；Early Experience范式把智能体生成的无奖励交互轨迹通过中间训练整合进模型参数。
  • 解决方案：把记忆作为已验证方案的仓库。ExpeL通过试错自动收集经验，成功轨迹作为示例，同时提取文本洞见；Synapse把抽象的状态-动作片段作为上下文示例注入。
4.2.2 基于策略的记忆（Strategy-based Memory）

从过去轨迹中提取可迁移的推理模式、工作流程和高层洞见，指导未来规划。分为三个粒度：

  • 原子洞见（Insights）：粒度最细的离散决策规则。H2R把规划级和执行级洞见解耦分别存储；Reflexion通过自我反思把失败转化为长期记忆中的反馈文本。
  • 工作流程（Workflows）：把策略封装为结构化动作序列。AWM（Agent Workflow Memory）从成功轨迹中归纳可复用工作流，无需更新基础模型权重即可提升成功率。
  • 模式（Patterns）：最高抽象层次，作为认知模板捕捉问题求解结构。Buffer of Thoughts维护思维模板元缓冲区；PRINCIPLES通过离线自我博弈构建策略记忆。
4.2.3 基于技能的记忆（Skill-based Memory）

把程序性能力（代码片段、函数、API、MCP协议）封装为可调用、可验证、可组合的执行单元，回答"智能体能做什么"。

  • 代码片段：Voyager在Minecraft中维护持续增长的技能库；Darwin Gödel Machine在实证验证下安全重写自身代码，实现自我递归进化。
  • 函数与脚本：SkillWeaver、LearnAct等从执行轨迹中提炼可检索脚本；RepairAgent把复杂调试行为模块化为可复用函数。
  • API：Gorilla微调模型正确调用工具；ToolLLM构建大规模工具调用训练数据；COLT、DRAFT等研究API的检索与重排。
  • MCP协议：Alita、Alita-G等利用Model Context Protocol统一工具发现和调用接口，减少协议碎片化。
4.2.4 混合记忆（Hybrid Memory）

同时维护案例、策略、技能多种形式，动态选择最合适的记忆格式。典型代表：G-Memory（三层图层次结构，从原始交互到查询到洞见）、LARP（世界知识+交互案例+程序性技能）。

4.3 工作记忆（Working Memory）

工作记忆是单个任务/会话内对活动上下文的动态管理机制，回答"智能体现在在想什么"。对应认知科学中的工作记忆模型（Baddeley, 2012），强调有限容量下的主动控制。

标准LLM上下文窗口只是被动的只读缓冲区，缺乏动态选择、维持、转换任务相关信息的能力。工作记忆研究的目标是把上下文窗口变成一个可控、可更新、抗干扰的工作空间。

4.3.1 单轮工作记忆（Single-turn Working Memory）

处理单次前向传播中面对海量输入（长文档、多模态流）的挑战。两类机制：

  • 输入凝缩（Input Condensation）：

  • 硬凝缩：基于重要性指标离散选择token。LLMLingua通过token困惑度丢弃可预测内容；LongLLMLingua面向多文档QA优化。

  • 软凝缩：把变长上下文编码为密集潜在向量。Gist、ICAE（In-Context AutoEncoder）、AutoCompressors把提示压缩为摘要token。
  • 混合方法：HyCo2结合全局语义适配器（软）和token级保留概率（硬）。
  • 观察抽象（Observation Abstraction）：把高维观察空间映射到固定大小的记忆状态。Synapse把HTML DOM树改写为面向任务的状态摘要；VideoAgent把视频流转化为时间事件描述和实体跨帧追踪。
4.3.2 多轮工作记忆（Multi-turn Working Memory）

解决长期交互中历史积累导致注意力预算饱和、延迟增加、目标漂移的问题。三类状态管理策略：

  • 状态合并（State Consolidation）：把持续增长的轨迹映射到固定大小的状态空间。MemAgent和MemSearcher用循环机制更新固定预算的记忆；MEM1维护一个合并新观察与先前记忆的共享内部状态；ReSum用RL优化摘要条件下的行为，以支持持续长程探索；处理更长的输入流不意味着有限状态具有无限信息容量。
  • 层次折叠（Hierarchical Folding）：按子目标分解任务轨迹，完成的子轨迹折叠为简洁摘要。HiAgent以子目标为记忆单元，活跃动作-观察对保留细节，子目标完成后写回摘要；Context-Folding和AgentFold把折叠操作学习为可训练策略。
  • 认知规划（Cognitive Planning）：在最高抽象层次上创建并维护外部化计划或世界模型作为工作记忆核心。SayPlan用3D场景图作为可查询环境记忆；Agent-S和KARMA通过记忆增强检索把长期知识与短期执行桥接起来。

五、动态（Dynamics）：记忆如何运作和演化？

这是论文第三个维度，研究记忆的生命周期。

5.1 记忆形成（Memory Formation）

将原始上下文（对话、图像等）编码为紧凑知识的过程。按照信息压缩的粒度和编码逻辑，分为五类：

5.1.1 语义摘要（Semantic Summarization）

将冗长原始数据转化为保留全局语义的紧凑摘要，过滤冗余，保留高层信息。

  • 增量语义摘要：新信息与已有摘要持续融合，形成演化的全局语义表示。早期方法（MemGPT、Mem0）直接融合，依赖LLM内在摘要能力；后续方法引入外部评估器过滤不连贯内容；最新方法（Mem1、MemAgent）用强化学习（PPO、GRPO）训练模型提升自身摘要能力。

  • 计算复杂度：增量处理避免了 $O(n^2)$ 的全序列计算，但串行更新存在瓶颈。

  • 分区语义摘要：按天/会话/话题等将信息分区后分别生成摘要，再层次聚合。ReadAgent和LightMem在分区前做语义聚类提升跨块连贯性；LangRepo对长视频分片后多源信号集成生成全局叙事。
5.1.2 知识蒸馏（Knowledge Distillation）

在更细粒度上提取可复用知识（声明性事实或经验性策略）：

  • 蒸馏事实记忆：TiM把对话轮转化为高层"思考"；MemGuide提取用户意图描述；M3-Agent把以自我为中心的视觉观察压缩为关于物体位置和用户习惯的文本事实。
  • 蒸馏经验记忆：AWM从成功案例提炼任务计划；ExpeL对比成功/失败经验提取整体洞见；Mem-α显式训练模型"应该提取什么洞见以及如何保留"。
5.1.3 结构化构建（Structured Construction）

将无结构数据转化为显式拓扑表示（知识图谱、层次树），增强可解释性和多跳推理能力。

  • 实体级构建：以三元组（主-谓-宾）为基本单元构建知识图谱。Mem0g利用LLM提取实体和关系三元组；D-SMART先把内容提炼为断言式语句再用神经符号流水线提取OWL兼容图；Zep形式化为三层时序图（情景子图 $G_e$、语义子图 $G_s$、社区子图 $G_c$）。
  • 块级构建：以完整文本段落为节点构建结构。RAPTOR用UMAP降维 + 高斯混合模型软聚类递归归纳树；MemTree用自底向上插入策略动态维护对话树；CAM建立语义相关性边后迭代摘要ego图，处理新记忆插入时显式解耦重叠聚簇。
5.1.4 潜在表示（Latent Representation）

直接把原始经验编码为模型原生的潜在嵌入，减少文本解码过程中的信息损失。

文本端：MemoryLLM和M+把记忆表示为可自更新的潜在嵌入，在推理时注入Transformer层；MemGen引入记忆触发器判断何时调用记忆，记忆编织器构建潜在token序列。

多模态端：CoMem通过Q-Former把视觉-语言输入压缩为固定长度token；KARMA把物体信息编码为多模态嵌入，混合长短期记忆形式。

5.1.5 参数内化（Parametric Internalization）

把外部记忆通过参数更新固化进模型权重，彻底消除外部存储和检索开销。分为：

  • 知识内化：通过模型编辑把事实直接写入权重。ROME用因果追踪定位编码特定事实的MLP层，执行秩-1更新（rank-one update）；MEMIT支持批量编辑，通过多层残差分布一次性更新上千条事实；CoLoR用LoRA适配器而非直接修改全参数，降低代价。
  • 能力内化：把程序性专长（解题模式、规划策略）内化进模型。通过SFT（监督微调）、DPO或GRPO从推理轨迹中学习；Memory Decoder是一个即插即用方法，不修改基础模型，同时获得参数内化推理的速度优势。

5.2 记忆演化（Memory Evolution）

记忆形成之后，如何将新记忆整合进已有记忆库——这是记忆演化要解决的问题。分三类机制：

5.2.1 记忆整合（Consolidation）

将新获得的短期轨迹转化为结构化、可泛化的长期知识，形成更高层次的抽象。

  • 局部整合：处理高度相似的记忆片段。RMM检索最相似的top-K候选后由LLM判断是否合并；VLN在容量满时识别最相似/冗余记忆对并压缩为高层抽象。
  • 聚类级融合：捕捉跨实例规律性。PREMem把新记忆聚簇与相似已有聚簇对齐，应用泛化/细化等融合模式形成高阶推理单元；CAM把目标聚簇内所有节点合并为代表性摘要。
  • 全局整合：维护全局连贯性，从积累经验中提炼系统级洞见。MOOM通过规则处理、嵌入方法和LLM驱动的抽象构建稳定角色画像；AgentFold和Context Folding把压缩工作记忆的能力内化为可学习策略。
5.2.2 记忆更新（Updating）

当新信息与已有记忆冲突时，修正或替换已有记忆，维护事实一致性，支持持续适应。

外部记忆更新的演进路径：规则触发的检测+替换（MemGPT、D-SMART）→ 软删除（Zep用无效时间戳代替物理删除，保留时序完整性）→ 双阶段更新（MOOM、LightMem：在线软更新保证实时响应，离线反思整合阶段解决冲突）→ RL优化更新策略（Mem-α将记忆更新决策建模为策略学习问题）。

模型编辑（内部参数更新）：ROME定位+秩-1更新；MEMIT批量多层更新。MemoryLLM 的潜在记忆池更新则应与基础模型权重编辑区分。

5.2.3 记忆遗忘（Forgetting）

主动删除过时、冗余或低价值信息，释放容量，防止知识过载。

  • 基于时间的遗忘：MemGPT在上下文溢出时驱逐最旧消息；MAICC通过随时间衰减权重实现软遗忘。
  • 基于频率的遗忘：XMem用LFU（最少使用频率）策略；KARMA用计数布隆过滤器追踪访问频率；MemOS用LRU策略。
  • 基于重要性的遗忘：综合时间衰减、访问频率和语义信号评估重要性。TiM和MemTool利用LLM判断记忆重要性，进行有意识的选择性遗忘。

注意：过激剪枝可能删除罕见但关键的长尾知识。因此很多系统在存储成本不是瓶颈时，倾向于不直接删除记忆，而是给低优先级记忆降权。

5.3 记忆检索（Memory Retrieval）

本节仅作导航：检索部分涵盖检索时机与意图、查询构建、检索策略和检索后处理。完整讨论见原论文 §5.3。

检索是记忆"被使用"的关键环节，核心问题是：何时检索、检索什么、如何检索、检索后如何处理。

  • 检索时机与意图：可以是任务初始化时一次性检索，也可以是在交互过程中基于上下文触发器动态检索，或持续检索。
  • 查询构建：如何从当前观察和任务说明中构建有效的检索查询，包括查询扩展、查询重写等。
  • 检索策略：向量相似度搜索（密集检索）、图遍历、关键词匹配、混合策略等，以及多跳检索。
  • 检索后处理：对检索结果做重排序、过滤、压缩，再送入LLM推理。

六、资源与框架

6.1 基准与数据集

论文整理了针对记忆/终身学习/自进化智能体的专用评测基准，包括：

  • 长对话记忆：LoCoMo（超长对话一致性）、LongMemEval（多会话记忆能力）
  • 深度研究：GAIA、XBench、BrowseComp
  • 代码智能体：SWE-bench Verified
  • 终身学习：StreamBench

6.2 开源框架

代表性的开源记忆框架包括Mem0（标准化记忆操作）、MemOS（操作系统式记忆管理）、Zep（时序知识图谱）、A-MEM（卡片式关联记忆网络）等。

七、前沿方向与展望

7.1 记忆检索 vs. 记忆生成

传统记忆依赖检索（在已有库中搜索相关内容），但当记忆库为空或任务需要创造新知识时，需要依靠模型自身生成记忆内容。未来方向是检索与生成的有机融合：检索提供锚点，生成进行推断补全。

7.2 自动化记忆管理

从手工设计记忆结构（固定Schema、人工设定规则）走向完全自动化的记忆系统构建。MemEvolve提出了元演化框架，让智能体不仅进化知识内容，也进化记忆架构本身。未来目标是让智能体自主决定存什么、用什么结构、何时遗忘。

7.3 强化学习与记忆的深度融合

RL可以训练智能体学会更好的记忆操作策略——何时写入、写什么、何时检索、如何遗忘。代表工作：MemAgent（GRPO优化记忆摘要）、Mem-α（RL训练记忆更新策略）、MEM1（RL优化单步记忆状态转移）。未来方向是将记忆管理完全内化为智能体RL策略的一部分。

7.4 多模态记忆

现有记忆研究以文本为主，但真实世界中智能体需要跨图像、视频、音频、3D点云等模态存储和检索知识。挑战在于：跨模态的统一表示空间、不同模态记忆的对齐机制、以及多模态记忆的有效压缩。

7.5 多智能体共享记忆

单体智能体记忆需要扩展到多智能体协作场景：多个智能体如何共享、读写、冲突解决共同记忆库，避免信息孤岛，同时防止共享记忆被恶意智能体污染。

7.6 记忆与世界模型

智能体的记忆可以被视为其对世界运作规律的隐式模型。如何让记忆系统不只存储过去发生的事，还能支持对未来状态的预测（世界模型），是一个重要的研究方向。

7.7 可信记忆（Trustworthy Memory）

记忆系统引入了新的安全和隐私风险：

  • 记忆投毒：恶意输入可以污染记忆库，影响后续推理。
  • 记忆泄露：用户私人信息可能通过记忆检索被未授权访问。
  • 幻觉传播：错误记忆一旦写入会持续影响推理。
  • 版权问题：记忆中存储的内容可能涉及版权。

7.8 与人类认知的深层联系

认知科学对情景记忆、语义记忆、工作记忆、遗忘曲线、记忆巩固等的研究，为AI记忆系统设计提供了丰富的灵感。未来值得借鉴的方向包括：记忆的情绪标注（情绪显著性影响记忆强度）、睡眠期记忆巩固的离线优化机制等。

八、总结

这篇综述的核心贡献是提出了"形式—功能—动态"三维统一框架，克服了"长期/短期"二分法的局限，系统性地整合了当前AI智能体记忆研究的庞杂文献，清晰区分了Token级、参数级、潜在三类记忆形式，细化了事实、经验、工作三类功能，并深入分析了形成、演化、检索三个动态过程。这一框架既是现有工作的分类工具，也为未来设计"记忆优先"的智能体系统提供了概念基础。

原文摘要

Memory has emerged, and will continue to remain, a core capability of foundation model-based agents. As research on agent memory rapidly expands and attracts unprecedented attention, the field has also become increasingly fragmented. Existing works that fall under the umbrella of agent memory often differ substantially in their motivations, implementations, and evaluation protocols, while the proliferation of loosely defined memory terminologies has further obscured conceptual clarity. Traditional taxonomies such as long/short-term memory have proven insufficient to capture the diversity of contemporary agent memory systems. This work aims to provide an up-to-date landscape of current agent memory research. We begin by clearly delineating the scope of agent memory and distinguishing it from related concepts such as LLM memory, retrieval augmented generation (RAG), and context engineering. We then examine agent memory through the unified lenses of forms, functions, and dynamics. From the perspective of forms, we identify three dominant realizations of agent memory, namely token-level, parametric, and latent memory. From the perspective of functions, we propose a finer-grained taxonomy that distinguishes factual, experiential, and working memory. From the perspective of dynamics, we analyze how memory is formed, evolved, and retrieved over time. To support practical development, we compile a comprehensive summary of memory benchmarks and open-source frameworks. Beyond consolidation, we articulate a forward-looking perspective on emerging research frontiers, including memory automation, reinforcement learning integration, multimodal memory, multi-agent memory, and trustworthiness issues. We hope this survey serves not only as a reference for existing work, but also as a conceptual foundation for rethinking memory as a first-class primitive in the design of future agentic intelligence.
