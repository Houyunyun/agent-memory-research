TRUSTMEM: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory

Tianyu Yang, Sudipta Paul, Vijay Srinivasan, Vivek Kulkarni, Srinivas Chappidi

论文原文 ↗下载文献卡片 Markdown

核心机制

过渡验证器评价覆盖、保持与忠实性，并训练记忆更新

适用范围与局限

主要文本场景；忠实不等于内容真实或有权执行

详细解读

论文核心总结

这篇论文提出了TRUSTMEM框架，旨在解决LLM（大语言模型）智能体在长期记忆管理中的可信性问题。现有的记忆智能体在自主执行写入、修改、删除等记忆更新操作时，容易引入三类持久性错误：遗漏（omission，丢失重要信息）、篡改（corruption，扭曲已有事实）和幻觉（hallucination，引入无依据内容）。这些错误一旦写入记忆库就会在后续交互中被反复检索和放大。TRUSTMEM的核心创新在于将监督粒度从"最终任务结果"下沉到"每一步记忆状态转换"，通过一个记忆转换验证器（Memory Transition Verifier）从覆盖性、保持性和忠实性三个维度评估每次局部记忆更新的可信度，并提出转换排序GRPO（Transition-Ranked GRPO）优化策略，利用验证器分数在同一记忆状态下的多个候选更新之间构建偏好对，从而以偏好引导的强化学习直接优化记忆编辑行为。实验表明TRUSTMEM在MemoryAgentBench、HaluMem和Mem-α验证集上均达到最优，并将遗漏、篡改和幻觉的转换级错误率分别降低了40.1%、79.1%和50.0%。

一、研究背景与动机

1.1 LLM智能体的长期记忆需求

当LLM从单轮对话工具演变为能够进行长期交互和个性化服务的智能体时，长期记忆（long-term memory）成为关键组件。由于LLM的上下文窗口是有限的，智能体需要通过维护一个外部记忆库来保存用户偏好、历史事实和推理轨迹，从而在多轮、跨会话的交互中保持一致性。
近期的研究已经从被动检索（即只在需要时从记忆中取出信息）发展到主动记忆管理：智能体在处理流式输入时，会主动执行结构化的记忆编辑操作，如插入新知识、更新已有记录或删除过时信息。

1.2 现有方法的核心问题

论文指出，虽然主动记忆管理增强了可控性，但引发了一个关键问题：我们能信任智能体自主生成的记忆更新吗？
论文通过具体案例展示了三类典型错误：

  • 篡改（Corruption）：输入明确说伏尔泰属于18世纪巴黎文学，但Mem1将其错误归入17世纪。
  • 遗漏（Omission）：输入包含乐队的分裂和重组时间线，但Mem1只保留了成立时间和创始人，丢失了关键的分裂/重组信息。
  • 幻觉（Hallucination）：输入只涉及仙人掌属的信息，但Mem-T在记忆中凭空加入了"John W. Ingram是Rock Island Railroad的总裁"这一完全无依据的事实。
    这些错误的危害在于其持久性和传播性：一旦错误信息被写入记忆，它会在后续交互中被反复检索，持续污染智能体的推理链，形成持久性系统状态故障。

1.3 现有训练范式的不足——信用分配鸿沟

现有的大多数训练方法依赖终端标量奖励（terminal scalar rewards），例如最终任务成功率或工具调用的有效性。这些奖励作用在整个轨迹层面，而非记忆更新的转换层面，存在严重的信用分配鸿沟（credit assignment gap）：

  • 一个错误的最终答案可能源于早期的遗漏、中途的破坏性覆写，或者仅仅是最后一步的推理失误——终端奖励无法区分这些情况。
  • 反过来，一个正确的最终答案可能掩盖了中间不安全的记忆更新，这些更新虽然没有在当前任务中触发失败，但作为潜在风险留存在记忆中，可能影响未来的任务。
    因此，仅依赖终端结果无法提供足够细粒度的监督来纠正智能体具体的记忆编辑行为。

二、TRUSTMEM框架

2.1 问题形式化：持续记忆更新

TRUSTMEM将记忆整合形式化为一个持续记忆更新问题。

  • 输入流：$C = \{c_1, c_2, \ldots, c_T\}$，其中$c_t$是第$t$步新观察到的输入块（chunk），可以是文档片段、对话轮次或任务演示段。
  • 记忆状态：$M_{t-1}$表示处理$c_t$之前的持久记忆状态，它存储了从之前所有块$c_1, \ldots, c_{t-1}$中积累的有用信息。
  • 动作生成：在第$t$步，智能体观察$(c_t, M_{t-1})$，生成一系列结构化记忆编辑动作$a_t \sim \pi_\theta(\cdot \mid c_t, M_{t-1})$。

2.2 统一动作空间

论文定义了一个统一的动作空间$\mathcal{A} = \{\text{WRITE}, \text{REVISE}, \text{PRUNE}\}$：

  • WRITE：当当前块包含记忆中尚未存储的有用信息时，插入新的记忆条目。
  • REVISE：当当前块提供了对已有记忆的修正、细化或补充证据时，更新或合并已有记忆条目。
  • PRUNE：当基于当前证据和已有记忆状态，某些记忆条目变得无效、冗余或不再对下游任务有用时，删除这些条目。
    如果当前块没有引入新的有用信息、不需要修正已有记忆、也不使任何已有条目无效或冗余，智能体可以不输出任何动作。
    一个确定性的记忆执行器（Memory Executor）$\mathcal{E}$将动作$a_t$应用到记忆库，产生更新后的状态$M_t = \mathcal{E}(M_{t-1}, a_t)$。这种增量构建定义了一个局部记忆转换$z_t = (c_t, M_{t-1}, a_t, M_t)$。

2.3 记忆转换验证器（Memory Transition Verifier）

这是TRUSTMEM的核心组件之一。验证器$V$评估每个局部记忆转换的可信度，产生一个分数$v_t = V(z_t) \in [0, 1]$。
验证器被实例化为一个冻结的LLM，它接收转换的紧凑视图，包括当前块、生成的记忆编辑动作，以及被这些动作触及或检索的记忆条目（而非整个记忆库），从而在提供足够判断证据的同时避免输入过长。
验证器从三个诊断维度评估每个转换：

  1. 覆盖性（Coverage）：检查当前块中的重要信息是否被保留在更新后的记忆中。这对应于检测遗漏错误。
  2. 保持性（Preservation）：检查之前记忆中的有效信息是否被维持，没有被无理由地删除或扭曲。这对应于检测篡改错误。
  3. 忠实性（Faithfulness）：检查新添加或修改的记忆内容是否有当前块或之前记忆状态的支持。这对应于检测幻觉错误。
    这三个判断被聚合为一个标量可信度分数$v_t = V(z_t) \in [0, 1]$，作为转换级验证奖励。

2.4 多粒度奖励设计

TRUSTMEM设计了一个多粒度奖励，结合了样本级奖励和转换级奖励。

样本级奖励（评估最终记忆状态$M_T^{(i)}$）
  • 任务奖励（$R_{\text{task}}$）：衡量下游任务效用。给定问题$Q^{(i)}$，固定的检索器$\mathcal{R}$和回答模型$g_{\text{ans}}$生成预测$\hat{y}$，奖励为与参考答案$y$对比的平均指标（如F1或LLM-as-a-judge分数）。
  • 效率奖励（$R_{\text{eff}}$）：惩罚记忆膨胀，防止过度复制，计算为$1 - (|M_T^{(i)}| / \sum_t |c_t^{(i)}|)$，鼓励紧凑记忆。
转换级奖励（评估每个局部转换$M_{t-1} \to M_t$）
  • 动作执行奖励（$R_{\text{act}}$）：检查生成的结构化动作是否可被记忆执行器$\mathcal{E}$解析和执行。
  • 内容类型奖励（$R_{\text{type}}$）：使用轻量分析器$J_{\text{type}}$确保修改的内容在语义上是具体的且非空的。
  • 验证器奖励（$R_{\text{ver}}$）：使用记忆转换验证器$V$评估转换的语义安全性，$R_{\text{ver},t}^{(i)} = V(z_{i,t})$。
    总奖励定义为：

$\displaystyle R_{i,t} = R_{\text{task}}^{(i)} + \lambda_{\text{eff}} R_{\text{eff}}^{(i)} + \lambda_{\text{act}} R_{\text{act},t}^{(i)} + \lambda_{\text{type}} R_{\text{type},t}^{(i)} + \lambda_{\text{ver}} R_{\text{ver},t}^{(i)}$

2.5 转换排序GRPO（Transition-Ranked GRPO）

这是TRUSTMEM的另一核心创新。它将标量奖励优化与验证器引导的转换排序结合起来。

全局轨迹优化（GRPO部分）

采用组相对策略优化（GRPO）来优化记忆策略。对于每个训练样本$i$，从旧策略$\pi_{\theta_{\text{old}}}$采样$G$个rollout。在每个块步$t$的rollout $g$中，计算标量奖励$R_{i,t}^{(g)}$。组归一化优势为：

$\displaystyle \hat{A}_{i,t}^{(g)} = \frac{R_{i,t}^{(g)} - \mu_{i,t}}{\sigma_{i,t} + \epsilon_A}$

其中$\mu_{i,t}$和$\sigma_{i,t}$是同一块步$G$个rollout奖励的均值和标准差。GRPO目标为：

$\displaystyle \mathcal{J}_{\text{GRPO}}(\theta) = \mathbb{E}_{i,t,g,l}\left[\min\left(r_{i,t,l}^{(g)}(\theta)\hat{A}_{i,t}^{(g)}, \text{clip}\left(r_{i,t,l}^{(g)}(\theta), 1-\epsilon, 1+\epsilon\right)\hat{A}_{i,t}^{(g)}\right)\right]$

其中$r_{i,t,l}^{(g)}(\theta)$是第$l$个生成token的重要性比率。

验证器引导的偏好对构建

关键洞察在于：虽然验证器分数的绝对值可能不总是校准良好的，但在同一记忆状态下生成的多个候选更新之间，验证器分数作为相对偏好是更鲁棒的。
对于每个训练样本$i$，$G$个rollout在每个块步$t$产生多个候选记忆转换$\mathcal{Z}_{i,t} = \{z_{i,t}^{(1)}, \ldots, z_{i,t}^{(G)}\}$。这些候选转换来自相同的当前块和之前记忆状态，但包含不同的记忆编辑动作。验证器$V$独立评估每个转换，从而在$\mathcal{Z}_{i,t}$上诱导一个排序。选择验证器分数最高和最低的转换分别作为偏好转换$z^+$和拒绝转换$z^-$，前提是它们的分数差超过一个阈值$\delta$。

局部偏好排序（DPO风格）

给定偏好对$(z^+, z^-)$，优化一个DPO风格的排序损失。由于$z^+$和$z^-$共享相同的提示$p_{i,t}$，只在生成的记忆编辑动作上不同。定义长度归一化的对数概率差：

$\displaystyle \Delta_\theta = \ell_\theta(o^+ \mid p_{i,t}) - \ell_\theta(o^- \mid p_{i,t})$

排序损失为：

$\displaystyle \mathcal{L}_{\text{rank}} = -\log \sigma(\beta_{\text{rank}}[\Delta_\theta - \Delta_{\text{ref}}])$

其中$\Delta_{\text{ref}} = \ell_{\text{ref}}(o^+ \mid p_{i,t}) - \ell_{\text{ref}}(o^- \mid p_{i,t})$是参考策略下的对应差值。

联合目标

最终训练目标结合标量奖励优化、KL正则化和转换级排序：

$\displaystyle \mathcal{L} = -\mathcal{J}_{\text{GRPO}} + \beta_{\text{KL}}\mathcal{L}_{\text{KL}} + \lambda_{\text{rank}}\mathcal{L}_{\text{rank}}$

三、实验设置

3.1 数据集

  • Mem-α验证集：使用Mem-α的训练池（聚合了SQuAD、HotpotQA、PerLTQA等8个来源），从4139个实例中平衡采样562个用于训练，463个用于验证。
  • MemoryAgentBench：评估三类记忆能力——准确检索（AR）、测试时学习（TTL）和长程理解（LRU）。
  • HaluMem：操作级基准，评估记忆提取、记忆更新和基于记忆的问答中的幻觉、遗漏和错误更新。使用HaluMem-Medium，包含20个用户的30073个对话轮次。

3.2 基线方法

三类基线：

  1. 标准范式：Long-Context（直接将历史放入上下文窗口）、RAG-Top2（检索前2个相关块）。
  2. 基于RL的记忆方法：Mem-α、MemAgent、MEM1、Mem-T、AtomMem。
  3. 系统级记忆框架：Mem0、Memobase、Supermemory、Zep。

3.3 实现细节

TRUSTMEM基于Qwen3-4B初始化，仅在Mem-α训练池上训练，使用32块NVIDIA H100 GPU训练约两天。MemoryAgentBench和HaluMem的数据均未用于训练，所有结果都在留出验证集或外部基准上报告。训练奖励为$R = R_{\text{task}} + R_{\text{act}} + 0.1R_{\text{ver}} + 0.05R_{\text{eff}} + 0.1R_{\text{type}}$。使用8个GRPO rollout，学习率$1 \times 10^{-6}$，KL系数0.001。偏好排序使用top-1/bottom-1对构建，分数阈值0.15，$\lambda_{\text{rank}} = 0.05$，$\beta_{\text{rank}} = 0.1$。

四、实验结果

4.1 记忆效用（Memory Utility）

Mem-α验证集（Table 1）：TRUSTMEM平均分66.3，超过最强基线Mem-α 4.4分。在测试时学习任务上提升尤为明显：TREC-C 72.4、NLU 73.8、PubMed 64.0。BookSum从18.7提升到22.6，表明更好的长程记忆效用。
MemoryAgentBench（Table 2）：TRUSTMEM平均分65.7，超过Mem-α 6.5分，超过Long-Context和RAG-Top2分别19.6和15.5分。在Single-Doc（83.0）、TREC-C（85.0）和Banking77（84.0）上取得最佳成绩。这些结果评估的是分布外泛化能力，说明TRUSTMEM学到了比简单保留长上下文或检索top-k块更鲁棒的记忆更新策略。

4.2 HaluMem操作级可靠性（Table 3）

  • 记忆提取：TRUSTMEM取得最佳召回率（56.73）、加权召回率（67.45）和F1（69.45），F1比之前最强的Mem0提高了12.14分。虽然AtomMem准确率最高（87.50），但其召回率和F1极低（0.28和0.56），说明过于保守。
  • 记忆更新：TRUSTMEM取得最低遗漏率（48.64），同时保持竞争力的正确率和低幻觉率。
  • 基于记忆的问答：TRUSTMEM取得最低遗漏率（12.46）和第二低幻觉率（6.07），同时保持竞争力的正确率。

4.3 消融研究（Table 4）

在Mem-α验证集上进行消融：

  • 去除$R_{\text{act}}$：总分从66.3降至54.0，降幅最大，说明可执行的记忆编辑动作对可靠记忆构建至关重要。
  • 去除$R_{\text{eff}}$：总分降至61.8，说明紧凑记忆状态有助于减少冗余。
  • 去除$R_{\text{ver}}$（记忆转换验证器）：总分从66.3降至58.7，TTL从70.1降至58.3，确认验证器提供了重要的转换级监督。
  • PRM风格GRPO vs. Transition-Ranked GRPO：后者将总分从60.3提升至66.3，TTL从57.6提升至70.1，说明对候选记忆转换进行排序比直接使用验证器分数作为标量奖励提供了更强的学习信号。

4.4 记忆整合的可靠性（Figure 2）

在463个Mem-α验证实例的生成轨迹上，使用GPT-4o-mini作为LLM判官评估转换级错误率：

  • 遗漏率：TRUSTMEM 8.08%，最强基线（AtomMem）13.48%，降低40.1%。
  • 篡改率：TRUSTMEM 0.14%，最强基线（AtomMem）0.67%，降低79.1%。
  • 幻觉率：TRUSTMEM 0.01%，最强基线（Mem-T）0.02%，降低50.0%。
    遗漏是主导错误类型（因为记忆构建本质上是压缩性的），而篡改和幻觉需要主动写入错误或无支持的事实，因此比率较低。

4.5 训练奖励动态（Figure 4）

对比TRUSTMEM与不使用Transition-Ranked GRPO的变体：两者在早期阶段都有改善，但不使用转换排序优化的变体后来变得不稳定，任务奖励和总奖励出现急剧下降；而TRUSTMEM保持较高奖励并收敛到稳定平台。这表明仅靠粗粒度标量奖励不足以实现可靠的记忆整合，转换排序GRPO通过验证器分数对候选记忆转换进行排序，提供了更细粒度的监督，鼓励可信更新并稳定训练。

4.6 案例研究（Table 5）

论文展示了多个代表性案例：

  • 篡改：MEM1将"18世纪的伏尔泰"错误归入17世纪；MEM1将"壁画没有幸存"反转为"壁画生动地覆盖墙壁和穹顶"。TRUSTMEM正确保留了时间线和否定语义。
  • 遗漏：MEM1丢失了乐队的分裂/重组时间线；MemAgent丢失了歌曲的UK排名和NME排名；AtomMem完全遗漏了所有关于身份象征服饰的事实。TRUSTMEM完整保留了这些关键信息。
  • 幻觉：Mem-T在仙人掌属信息中凭空加入铁路总裁信息；Mem-T在军事基地信息中凭空加入嘻哈组合和电视节目信息；MemAgent将标注命令示例误解为真实用户事件。TRUSTMEM避免了这些无依据的记忆写入。

五、与相关工作的区别

论文将相关工作分为三类，并明确了TRUSTMEM的定位：

  1. 长期记忆系统（如MemGPT、Mem0、A-MEM等）：主要研究记忆如何存储、检索、压缩或表示，而TRUSTMEM关注的是每个生成的记忆更新在存储之前是否可信。
  2. 基于RL的记忆智能体（如MemAgent、MEM1、Memory-R1、Mem-α等）：虽然证明了RL可以提升记忆效用，但主要优化最终任务性能或轨迹级奖励。TRUSTMEM引入了转换级验证和偏好排序来监督每个局部记忆更新的安全性。
  3. 可靠记忆智能体（如HaluMem基准、记忆注入攻击研究等）：这些工作侧重于评估或防御，而TRUSTMEM直接通过转换级验证优化记忆更新策略，在不安全更新变为持久性错误之前就加以阻止。

六、局限性

论文指出TRUSTMEM目前主要在基于文本的长期记忆基准上实验。然而在真实的智能体应用中，用户输入和记忆证据通常是多模态的（包括图像、视频、文档等）。作者计划将框架扩展到多模态记忆智能体和视觉-语言模型。

七、核心贡献总结

  1. 问题定义：首次系统性地将LLM记忆智能体的可信性问题从终端评估转移到转换级评估，识别出遗漏、篡改和幻觉三类转换级错误。
  2. 记忆转换验证器：设计了一个基于冻结LLM的验证器，从覆盖性、保持性和忠实性三个维度评估每次局部记忆更新。
  3. Transition-Ranked GRPO：提出将验证器分数用于在同一记忆状态下的候选更新之间构建偏好对，结合GRPO的标量奖励优化和DPO风格的偏好排序，形成联合训练目标。
  4. 实验验证：在三个基准上达到最优，同时在记忆效用和操作级可靠性两个维度都取得了显著提升。

研究问题 LLM智能体在长期记忆巩固过程中，自主生成的记忆更新可能引入遗漏、篡改和幻觉等持久性错误，现有基于终端奖励的训练范式因信用分配粒度过粗而无法有效定位和纠正这些中间步骤的错误。
研究方法 提出TRUSTMEM框架，包含：(1) 记忆转换验证器（Memory Transition Verifier），从覆盖性、保持性和忠实性三个维度评估每步记忆更新的可信度；(2) 转换排序GRPO（Transition-Ranked GRPO），基于GRPO结合验证器分数构建偏好对，通过多粒度奖励和DPO风格排序损失联合优化记忆更新策略。模型基于Qwen3-4B初始化，在Mem-α训练集上使用强化学习训练。
主要发现 TRUSTMEM在MemoryAgentBench、HaluMem和Mem-α验证集上均达到最优结果，在MemoryAgentBench上比最强基线提升6.5分，在HaluMem记忆提取F1上提升12.14分。在转换级错误率方面，与各错误类型的最强基线相比，遗漏、篡改和幻觉分别降低40.1%、79.1%和50.0%。
创新点 (1) 将记忆巩固的可信度评估从终端结果层面转移到每步转换层面，提出记忆转换验证器进行细粒度监督；(2) 提出Transition-Ranked GRPO，利用验证器分数在相同记忆状态下对候选更新进行偏好排序，结合标量奖励优化和转换级偏好排序的联合训练目标；(3) 设计多粒度奖励体系，融合样本级任务/效率奖励与转换级执行/内容/验证奖励。
局限性 当前实验主要集中在文本类长期记忆基准上，尚未扩展到多模态场景（如图像、视频、文档等），而真实智能体应用中用户输入和记忆证据往往是多模态的。

原文摘要

Large language model (LLM) agents rely on long-term memory to support extended interactions and personalized assistance beyond finite context windows. Existing memory agents actively update external memory through generated write, revise, and delete operations, but these updates may omit important information, corrupt existing memory, or introduce unsupported hallucinated content. Once stored, such errors become persistent system-state failures that can affect future reasoning and generation. In this paper, we propose TrustMem, a framework designed to improve the trustworthiness of memory consolidation. TrustMem relies on a Memory Transition Verifier to evaluate the transition process of memory updates in terms of coverage, preservation, and faithfulness. It further constructs preference pairs among candidate updates under the same memory state, enabling preference-guided reinforcement learning to directly optimize memory updating behaviors. Extensive experiments demonstrate that TrustMem improves both memory utility and reliability: it achieves state-of-the-art results across MemoryAgentBench, HaluMem, and the Mem-alpha validation set, improves HaluMem memory extraction by 12.14 F1 points, and reduces transition-level omission, corruption, and hallucination by 40.1\%, 79.1\%, and 50.0\%, respectively, compared with the strongest baseline for each error type.
