  • 建立全景：研究总览按八个方向组织问题；中文综述比较记忆架构、经验学习、评测和治理。Huang 等“Second Half”综述提供按记忆基底、认知机制和主体展开的详细解读与研究要点表。
  • 查找具体论文：文献库支持题名、作者、论文标识和中文关键词搜索，以及研究方向、年份和范围筛选。
  • 理解团队记忆：多智能体专题区分团队共享经验、角色适配和由多个 Agent 管理记忆。

一张文献卡片里有什么

先看“核心机制”和“适用范围与局限”，判断论文是否与你的问题相关。部分卡片另提供：

  • 详细解读：研究动机、方法步骤、实验设置、主要发现和局限。
  • 研究要点表：快速对照问题、方法、结果与适用条件。
  • 结构化提纲：按层级回顾论文的逻辑。
  • 章节解读：按章节展开方法、实验与讨论，便于对照原文。
  • 原文摘要与论文链接：回到原论文阅读图表、公式和完整论证。

详细解读是帮助理解的整理文字，不代替原文。引用实验数字或理论结论时，请查看论文的对应版本、条件和图表。

怎么比较不同方法

先问改变了什么。 新增记忆内容、学习记忆操作、搜索记忆架构，以及改变外层改进规则，是不同层次的贡献。

再看测试条件。 同一数字在不同模型、历史长度、数据划分和计算预算下含义不同。“成本降低”要区分构建、检索、推理和整个生命周期；“零违规”也需要结合样本量和威胁模型理解。

保留不成功的情况。 完整上下文可能优于记忆压缩；更多共享也可能增加干扰。阅读实验结论时，注意基线、负迁移和防御对正常任务的影响。

不要混淆来源与权限。 在记忆安全研究中，“信息来自哪里”和“谁有权授予行动权限”是研究对象本身。保留信息出处，不等于允许 Agent 执行其中的指令。

经验演化与安全：新增阅读入口

  • CoEvoSkills：技能生成器与代理验证器共同演化；注意隐藏真实测试仍提供外部反馈。
  • 经验驱动自进化的安全风险：良性经验也可能在风险场景中发生负迁移，拒绝经验可能增加误拒。
  • LLM 投毒与防御综述：从权重投毒到上下文、记忆与工具投毒；区分通用综述与 Agent Memory 专题。
  • FATE：用失败轨迹修复监督进行策略训练，与固定模型的记忆准入区分。
  • HaluMem：从抽取、更新和问答环节定位记忆幻觉，现已提供详细解读。

多智能体、评测与技能审计

  • G-Memory：洞察、查询和交互三层图如何支持团队经验复用；任务收益不等于记忆可信。
  • MemoryAgentBench：增量多轮交互中的检索、测试时学习、长程理解和选择性遗忘；冲突消解不等于数据删除。
  • Proteus：反馈驱动的多轮技能攻击；区分审计绕过、沙箱副作用与跨审计器迁移。
