# A-MEM: Agentic Memory for LLM Agents

Xu, Wujiang, Liang, Zujie, Mei, Kai, Gao, Hang, Tan, Juntao, Zhang, Yongfeng · 2025

[论文原文](https://arxiv.org/abs/2502.12110)

## 核心机制

属性化笔记、语义链接及历史节点更新

## 适用范围与局限

节点更新不等于学习更新规则；网络关联不保证来源可信

## 详细解读

### 论文核心总结

这篇论文提出了 A-MEM，一种面向大语言模型（LLM）智能体的"智能体式记忆系统"（Agentic Memory）。其核心思想是借鉴知识管理领域经典的 Zettelkasten（卡片盒）笔记方法，让 LLM 智能体的记忆系统能够以自主、动态的方式组织和演化记忆，而非依赖预定义的固定存储结构和操作流程。系统在每条新记忆写入时，自动生成包含上下文描述、关键词、标签等多维属性的结构化笔记，然后通过嵌入相似度检索和 LLM 分析来自动建立记忆之间的链接关系，并且在整合新记忆的过程中触发对已有历史记忆的更新演化，使整个记忆网络持续自我完善。实验在六种基础模型上进行评估，在长期对话问答任务中显著优于现有基线方法，同时大幅降低了 token 消耗。

### 一、研究背景与动机

#### 1.1 LLM 智能体的记忆需求

大语言模型智能体已经展现出强大的推理和规划能力，能够与外部环境交互、执行任务并自主决策。然而，要实现与外部环境的**长期交互**，智能体需要一个记忆系统来存储和利用历史经验。

#### 1.2 现有记忆系统的局限性

现有的 LLM 智能体记忆系统（如 MemGPT、MemoryBank 等）存在以下关键问题：

1. **固定的存储结构**：开发者需要预先定义记忆的存储结构、存储时机和检索时机，这些都是在工作流中硬编码的。
2. **固定的操作模式**：记忆的读写操作是预设的，缺乏灵活性。
3. **图数据库的局限**：虽然 Mem0 等系统引入了图数据库来改善结构化组织，但图数据库依赖于预定义的 schema 和关系，这从根本上限制了其适应性。  
   举个例子：当智能体学到一种新的数学解法时，现有系统只能在预设的框架内对这条信息进行分类和链接，无法自主地建立创新性的连接或发展出新的组织模式。  
   论文 Figure 1 直观对比了传统记忆系统和 A-MEM 的区别：传统系统中，LLM 智能体通过预定义的读写模式与记忆交互；而 A-MEM 则让记忆系统本身具备"智能体性"（agency），能够动态地自主管理记忆。

### 二、核心方法论

A-MEM 的设计灵感来源于 **Zettelkasten 方法**。Zettelkasten 是一种知识管理方法，核心理念是：将知识拆分为**原子化的笔记**（每张卡片只记录一个独立的知识单元），然后通过**灵活的链接机制**将这些笔记互联，形成一个不断生长的知识网络。  
A-MEM 的架构包含四个核心模块：**笔记构建（Note Construction）**、**链接生成（Link Generation）**、**记忆演化（Memory Evolution）**和**相关记忆检索（Retrieve Relative Memory）**。

#### 2.1 笔记构建（Note Construction）

当智能体与环境交互产生新的记忆时，系统将其构建为一个结构化的记忆笔记。每条记忆 $m_i$ 在记忆集合 $\mathcal{M} = \{m_1, m_2, ..., m_N\}$ 中表示为：  

$\displaystyle m_i = \{c_i, t_i, K_i, G_i, X_i, e_i, L_i\}$

  
各字段含义如下：

- $c_i$：原始交互内容（即对话原文）
- $t_i$：交互的时间戳
- $K_i$：LLM 生成的**关键词**，捕捉核心概念
- $G_i$：LLM 生成的**标签**，用于分类
- $X_i$：LLM 生成的**上下文描述**，提供丰富的语义理解
- $e_i$：嵌入向量，用于相似度匹配
- $L_i$：链接集合，记录与该记忆有语义关系的其他记忆  
  其中，关键词、标签和上下文描述是通过 LLM 自动生成的。具体来说，系统使用精心设计的提示模板 $P_{s1}$ 来引导 LLM 分析交互内容：  

  $\displaystyle K_i, G_i, X_i \leftarrow \text{LLM}(c_i \| t_i \| P_{s1})$

    
  这里 $\|$ 表示拼接操作。提示模板要求 LLM 识别最显著的关键词、提取核心主题和上下文元素、创建分类标签，并以 JSON 格式输出。  
  为了支持高效的检索和链接，系统还通过文本编码器（论文使用 all-minilm-l6-v2 模型）计算一个稠密向量表示，将笔记的所有文本组件编码到一个向量中：  

  $\displaystyle e_i = f_{\text{enc}}[\text{concat}(c_i, K_i, G_i, X_i)]$

    
  这种设计的好处在于：LLM 生成的丰富组件（关键词、标签、上下文描述）使得每条记忆具有多维度的语义表示，而稠密向量则提供了计算高效的相似度匹配能力。

#### 2.2 链接生成（Link Generation）

这是 A-MEM 最核心的创新之一。当一条新构建的记忆笔记 $m_n$ 被加入系统时，系统会自动寻找并建立与历史记忆的有意义连接。  
**第一步：基于嵌入的相似度检索。** 对于记忆库中每条已有记忆 $m_j \in \mathcal{M}$，计算余弦相似度：  

$\displaystyle s_{n,j} = \frac{e_n \cdot e_j}{|e_n||e_j|}$

  
然后找出 top-$k$ 最相关的历史记忆：  

$\displaystyle \mathcal{M}_{\text{near}}^n = \{m_j | \text{rank}(s_{n,j}) \leq k, m_j \in \mathcal{M}\}$

  
**第二步：LLM 驱动的链接分析。** 将新记忆和候选最近邻记忆一起送入 LLM，由 LLM 判断是否应该建立连接：  

$\displaystyle L_i \leftarrow \text{LLM}(m_n \| \mathcal{M}_{\text{near}}^n \| P_{s2})$

  
每个生成的链接集合结构为 $L_i = \{m_i, ..., m_k\}$。  
这种两阶段设计的优势在于：嵌入检索作为初始过滤器保证了效率和可扩展性，而 LLM 分析则能发现超越简单相似度的深层关系——比如因果关系、概念联系等。论文中用"Box"的概念来描述这种链接关系：相关的记忆通过相似的上下文描述被互联到同一个"盒子"中，但一条记忆可以同时属于多个不同的盒子。

#### 2.3 记忆演化（Memory Evolution）

这是 A-MEM 的另一个关键创新。在为新记忆创建链接之后，系统还会**反过来更新那些被链接到的历史记忆**。对于最近邻集合 $\mathcal{M}_{\text{near}}^n$ 中的每条记忆 $m_j$，系统判断是否需要更新其上下文描述、关键词和标签：  

$\displaystyle m_j^\* \leftarrow \text{LLM}(m_n \| \mathcal{M}_{\text{near}}^n \setminus m_j \| m_j \| P_{s3})$

  
更新后的记忆 $m_j^\*$ 会替换原始记忆 $m_j$。  
这个演化过程模拟了人类的学习过程：当我们获得新知识时，不仅会记住新知识本身，还会重新审视和更新已有的知识理解。随着系统处理越来越多的记忆，它会发展出越来越复杂的知识结构，发现跨多条记忆的高阶模式和概念。  
从提示模板（Appendix B.3）可以看到，记忆演化的具体操作包括：

- **strengthen（加强连接）**：确定新记忆应该与哪些历史记忆建立连接，并更新标签
- **update_neighbor（更新邻居）**：基于对这些记忆的综合理解，更新邻居记忆的上下文描述和标签

#### 2.4 相关记忆检索（Retrieve Relative Memory）

在每次交互中，系统执行上下文感知的记忆检索。给定当前交互的查询文本 $q$，首先用同一个文本编码器计算查询嵌入：  

$\displaystyle e_q = f_{\text{enc}}(q)$

  
然后计算查询与所有记忆的余弦相似度：  

$\displaystyle s_{q,i} = \frac{e_q \cdot e_i}{|e_q||e_i|}, \text{ where } e_i \in m_i, \forall m_i \in \mathcal{M}$

  
检索 top-$k$ 最相关的记忆：  

$\displaystyle \mathcal{M}_{\text{retrieved}} = \{m_i | \text{rank}(s_{q,i}) \leq k, m_i \in \mathcal{M}\}$

  
一个重要的设计细节是：当某条记忆被检索到时，与它在同一个"Box"中链接的相似记忆也会被自动访问。这使得系统能够利用记忆之间的关联关系，提供更丰富的上下文信息。

### 三、与现有工作的区别

#### 3.1 与传统记忆系统的区别

传统记忆系统（MemGPT、MemoryBank、SCM 等）的操作是预定义的、固定的。它们可能使用缓存架构（MemGPT）、遗忘曲线（MemoryBank）或记忆流控制器（SCM）等机制，但这些机制都是在设计时就确定的，无法根据记忆内容动态调整。A-MEM 的"智能体性"体现在记忆系统自身能够自主决定如何组织、链接和演化记忆。

#### 3.2 与 Agentic RAG 的区别

Agentic RAG 系统在**检索阶段**展现智能体性——自主决定何时检索、检索什么。而 A-MEM 在更基础的层面展现智能体性——在**存储和演化阶段**。A-MEM 让记忆能够主动生成自己的上下文描述、与相关记忆建立有意义的连接、并随着新经验的出现而演化内容和关系。Agentic RAG 维护的是静态知识库，而 A-MEM 的知识库是动态演化的。

### 四、实验设计与结果

#### 4.1 数据集

论文使用了两个数据集：

1. **LoCoMo 数据集**：包含显著更长的对话（平均 9K tokens，跨越多达 35 个会话），共 7,512 个问答对。问题类型包括：
   - 单跳问题（Single Hop）：从单个会话即可回答
   - 多跳问题（Multi Hop）：需要跨会话综合信息
   - 时间推理问题（Temporal）：测试对时间信息的理解
   - 开放域知识问题（Open Domain）：需要结合对话上下文和外部知识
   - 对抗性问题（Adversarial）：评估模型识别不可回答问题的能力
2. **DialSim 数据集**：来源于长期多方对话的问答数据集，基于热门电视剧（Friends、The Big Bang Theory、The Office），覆盖 1,300 个会话、约 350,000 tokens。

#### 4.2 基线方法

- **LoCoMo**：直接将完整对话历史放入提示中，不使用记忆机制
- **ReadAgent**：通过分页、记忆摘要和交互式查找三步处理长上下文
- **MemoryBank**：基于艾宾浩斯遗忘曲线的动态记忆更新机制
- **MemGPT**：借鉴操作系统内存层次的双层上下文管理系统

#### 4.3 评估指标

主要指标为 F1 分数和 BLEU-1，附加指标包括 ROUGE-L、ROUGE-2、METEOR 和 SBERT Similarity。

#### 4.4 主要实验结果

论文在六种基础模型上进行了实验：GPT-4o-mini、GPT-4o、Qwen2.5-1.5B、Qwen2.5-3B、Llama 3.2-1B、Llama 3.2-3B。  
**关键发现：**

1. **非 GPT 模型**（Qwen2.5 和 Llama 3.2 系列）：A-MEM 在所有类别上一致性地超越所有基线。例如，Llama 3.2-3B 上，A-MEM 的 Multi Hop F1 达到 17.44，而最好的基线仅为 6.88。
2. **GPT 模型**：LoCoMo 和 MemGPT 在某些类别（如 Open Domain 和 Adversarial）表现较强，这得益于 GPT 强大的预训练知识。但 A-MEM 在 **Multi Hop 任务上表现尤为突出**，达到至少两倍于基线的性能。例如，GPT-4o-mini 上 Temporal 类别，A-MEM 的 F1 为 45.85，而 MemGPT 仅为 25.52。
3. **DialSim 数据集**：A-MEM 的 F1 达到 3.45，比 LoCoMo 的 2.55 提升 35%，比 MemGPT 的 1.18 提升 192%。

#### 4.5 成本效率分析

A-MEM 展现了显著的计算和成本效率优势：

- 每次记忆操作仅需约 **1,200 tokens**，相比 LoCoMo 和 MemGPT 的 16,900 tokens 减少了 **85-93%**
- 使用商业 API 时，每次操作成本低于 **$0.0003**
- 处理时间：GPT-4o-mini 平均 5.4 秒，本地部署 Llama 3.2 1B 仅需 1.1 秒  
  这种效率提升主要来自选择性的 top-$k$ 检索机制——不需要将全部对话历史放入提示中。

#### 4.6 消融实验

消融实验验证了链接生成（LG）和记忆演化（ME）两个模块的有效性：

| 配置 | Multi Hop F1 | Temporal F1 | Single Hop F1 |
| --- | --- | --- | --- |
| w/o LG & ME | 9.65 | 24.55 | 13.28 |
| w/o ME | 21.35 | 31.24 | 39.17 |
| A-MEM（完整） | 27.02 | 45.85 | 44.65 |

结果表明：

- 移除两个模块后性能大幅下降，特别是在多跳推理任务上
- 仅有链接生成（w/o ME）已经能显著提升性能，说明链接生成是记忆组织的关键基础
- 加入记忆演化后进一步提升，说明两个模块具有互补性

#### 4.7 超参数分析

论文分析了检索参数 $k$（检索的记忆数量）的影响。在 $k$ 从 10 增加到 50 的过程中：

- 性能通常随 $k$ 增大而提升
- 但提升逐渐趋于平缓，有时在较高值时略有下降
- 这表明存在一个平衡点：更大的 $k$ 提供更丰富的历史上下文，但也可能引入噪声

#### 4.8 可扩展性分析

论文在 1,000 到 1,000,000 条记忆的规模上测试了系统的扩展性：

- **空间复杂度**：所有系统都是线性 $O(N)$ 增长，A-MEM 不引入额外存储开销
- **检索时间**：A-MEM 从 0.31μs 增长到 3.70μs（百万级记忆），表现优异。虽然 MemoryBank 略快（1.91μs），但 A-MEM 提供了更丰富的记忆表示和功能

#### 4.9 记忆可视化分析

通过 t-SNE 可视化，论文展示了 A-MEM 的记忆嵌入比基线系统具有更清晰的聚类模式。A-MEM（蓝色点）形成了更连贯的簇结构，而没有链接生成和记忆演化的基线系统（红色点）则呈现更分散的分布。这直观地验证了 A-MEM 能够通过动态演化和链接机制自主维护有意义的记忆结构。

### 五、局限性

论文承认了以下局限：

1. 记忆组织的质量仍受底层语言模型能力的影响——不同 LLM 可能生成不同的上下文描述或建立不同的连接
2. 当前实现仅聚焦于文本交互，未来可以扩展到多模态信息（图像、音频等）

---

### 六、总结性评价

A-MEM 的核心贡献在于将记忆系统从"被动存储工具"提升为"主动知识管理智能体"。通过 Zettelkasten 方法的原子化笔记和灵活链接原则，结合 LLM 的语义理解能力，实现了三个关键能力：（1）自动生成丰富的多维度记忆表示；（2）自主发现和建立记忆间的语义连接；（3）在整合新记忆时动态演化已有记忆。这种设计使得记忆网络能够随着交互的积累而持续自我完善，特别适合需要复杂多跳推理的长期交互场景。

## 原文摘要

While large language model (LLM) agents can effectively use external tools for complex real-world tasks, they require memory systems to leverage historical experiences. Current memory systems enable basic storage and retrieval but lack sophisticated memory organization, despite recent attempts to incorporate graph databases. Moreover, these systems' fixed operations and structures limit their adaptability across diverse tasks. To address this limitation, this paper proposes a novel agentic memory system for LLM agents that can dynamically organize memories in an agentic way. Following the basic principles of the Zettelkasten method, we designed our memory system to create interconnected knowledge networks through dynamic indexing and linking. When a new memory is added, we generate a comprehensive note containing multiple structured attributes, including contextual descriptions, keywords, and tags. The system then analyzes historical memories to identify relevant connections, establishing links where meaningful similarities exist. Additionally, this process enables memory evolution - as new memories are integrated, they can trigger updates to the contextual representations and attributes of existing historical memories, allowing the memory network to continuously refine its understanding. Our approach combines the structured organization principles of Zettelkasten with the flexibility of agent-driven decision making, allowing for more adaptive and context-aware memory management. Empirical experiments on six foundation models show superior improvement against existing SOTA baselines.
