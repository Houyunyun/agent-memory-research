# MemVenom: Triggered Poisoning of Multimodal Memories in Web Agents

Zhang, Yv, Sun, Hao, Fang, Hao, Gao, Kuofeng, Mo, Fan, Chen, Bin, Xia, Shu-Tao, Wang, Yaowei · 2026

[论文原文](https://arxiv.org/abs/2606.10742)

## 核心机制

对多模态外部记忆的检索与使用进行协同污染

## 适用范围与局限

攻击者记忆控制权限与图像受限攻击不同

## 详细解读

### 论文核心总结

这篇论文提出了MemVenom，一个针对配备外部记忆系统的多模态Web智能体的黑盒记忆投毒攻击框架。现代Web智能体（如能自主浏览网页、执行订票、搜索等任务的AI系统）越来越依赖外部图结构记忆来存储和检索过去的经验，而这种持久性记忆引入了一个被忽视的安全漏洞：攻击者可以向记忆中注入协调的文本-图像恶意证据，通过视觉触发器条件性地激活恶意记忆召回，并在召回后通过对抗性扰动和隐蔽OCR注入诱导智能体执行攻击者指定的恶意操作。该攻击分两阶段设计——检索阶段优化和召回后行为诱导——并支持模块化的恶意目标替换，在多个Web智能体框架和视觉语言模型上实现了高达99.15%的端到端攻击成功率。

### 详细讲解

#### 1. 研究背景与动机

**Web智能体与外部记忆**：近年来，视觉语言模型（VLM）的发展使得Web智能体能够自主与真实网站交互，执行多步骤任务（如信息搜索、预订、在线交易等）。为了支持长期决策，现代Web智能体引入了外部记忆系统，将过去的观察（如网页截图）和经验存储起来，在后续决策时通过检索相关记忆来辅助推理。  
**安全漏洞**：与瞬时的提示输入不同，外部记忆具有**持久性**——一旦写入，可以被反复检索并持续影响未来决策。这意味着如果记忆被投毒，恶意内容不仅会被召回，还会在多个决策步骤中传播，产生长期的复合效应。  
**现有研究的不足**：已有的智能体安全研究主要集中在提示注入（prompt injection）、越狱攻击（jailbreak）或纯文本的检索投毒上。这些方法要么只作用于当前输入上下文，要么只假设纯文本记忆。而实际的Web智能体操作的是网页截图等多模态观察，其外部记忆同时存储文本和视觉证据。如何在多模态记忆中注入恶意内容、确保其被召回、并最终转化为下游智能体动作，这个问题此前尚未被系统研究。

#### 2. 威胁模型

论文定义了一个现实的**黑盒威胁模型**：

- **攻击场景**：攻击者无法访问专有的VLM、检索器内部机制或记忆评分函数。但Web智能体的记忆可能来自不可信的网页观察、用户交互、共享记忆集合或第三方数据源。攻击者通过向这些记忆中注入精心构造的多模态条目来实施攻击。
- **攻击者能力**：攻击者只有**记忆级别的访问权限**。不能修改VLM骨干网络、策略模型、检索编码器、动作解析器、推理提示或内部评分。只能在部署前或离线索引阶段注入少量多模态记忆条目（包含文本、图像和图关系）。
- **攻击者目标**：在保持正常观察下的良性功能的同时，诱导智能体执行攻击者指定的恶意侧目标 $g_m$。恶意记忆仅在包含触发器的观察下被激活。由于恶意目标被隔离在可替换的目标承载组件中，切换到新的侧目标只需替换该组件，无需重新优化触发器或召回后优先级组件。

#### 3. MemVenom攻击框架

整个框架考虑一个配备记忆的Web智能体：接收用户目标 $g_u$，在每一步 $t$ 观察当前网页状态 $o_t$，从图结构记忆 $\mathcal{M} = (\mathcal{V}, \mathcal{E})$ 中检索记忆 $r_t = \mathcal{R}(o_t, \mathcal{M})$，然后生成动作 $a_t = \pi(g_u, o_t, r_t)$。  
攻击框架分为**两个阶段**加上一个**组装步骤**。

##### 3.1 第一阶段：检索阶段优化（Retrieval-Stage Optimization）

**目标**：确保当网页观察中出现视觉触发器时，恶意记忆能被可靠地召回。  
**方法**：

1. 收集一组代表性的干净网页截图 $\mathcal{Q}_{\text{raw}} = \{q_1, q_2, \ldots, q_N\}$。
2. 定义渲染算子 $\mathcal{T}_\tau(\cdot)$，将视觉触发器 $\tau$ 放置在截图的固定区域，得到触发截图集 $\mathcal{Q}_\tau = \{\mathcal{T}_\tau(q_i)\}_{i=1}^N$。
3. 设 $\phi(\cdot)$ 为检索模块使用的图像编码器。定义触发聚类中心和原始观察中心：  

   $\displaystyle C(\tau) = \frac{1}{N}\sum_{i=1}^{N}\phi(\mathcal{T}_\tau(q_i)), \quad C_{\text{raw}} = \frac{1}{N}\sum_{i=1}^{N}\phi(q_i).$
4. 优化触发器有两个目标：
   - **紧凑性**：不同的触发网页应在嵌入空间中形成紧凑聚类，使它们倾向于检索到同一个恶意组件。
   - **分离性**：触发聚类应与干净观察和良性记忆空间保持分离，使非触发执行不受影响。  
     优化目标为：  

     $\displaystyle \tau^\star = \arg\min_{\tau \in \Omega}\left[\mathcal{L}_{\text{cmp}}(\tau) - \lambda_{\text{sep}} d\big(C(\tau), C_{\text{raw}}\big) + \lambda_{\text{reg}}\mathcal{L}_{\text{reg}}(\tau) + \lambda_{\text{space}}\mathcal{L}_{\text{space}}(\tau)\right],$

       

     $\displaystyle \mathcal{L}_{\text{cmp}}(\tau) = \frac{1}{N}\sum_{i=1}^{N}d\big(\phi(\mathcal{T}_\tau(q_i)), C(\tau)\big).$

       
     其中 $d(\cdot,\cdot)$ 是检索嵌入空间中的距离函数，$\Omega$ 约束触发器位置和大小，$\mathcal{L}_{\text{reg}}$ 正则化触发器外观。空间分离项定义为：  

     $\displaystyle \mathcal{L}_{\text{space}}(\tau) = -\frac{1}{NB}\sum_{i=1}^{N}\sum_{j=1}^{B}d\big(\phi(\mathcal{T}_\tau(q_i)), b_j\big),$

       
     其中 $\mathcal{B} = \{b_j\}_{j=1}^B$ 是现有记忆项的嵌入。
5. 优化完成后，选择嵌入最接近触发中心 $C_t = C(\tau^\star)$ 的触发截图：  

   $\displaystyle x^\star_{\text{ret}} = \arg\min_{x \in \mathcal{Q}_{\tau^\star}} d\big(\phi(x), C_t\big).$
6. 构建召回导向记忆节点 $v^\star_{\text{ret}} := v_{\text{ret}}(x^\star_{\text{ret}})$，将 $x^\star_{\text{ret}}$ 作为图像证据插入。

**直觉理解**：这一阶段本质上是在检索嵌入空间中"开辟"一个专属区域。当网页截图中出现特定的视觉触发器（比如一个小图标或图案）时，该截图的嵌入会落入这个专属区域，从而高概率地检索到预先放置在该区域的恶意记忆节点。而没有触发器的正常截图则不会落入该区域，因此不受影响。

##### 3.2 第二阶段：召回后复合视觉攻击（Post-Recall Composite Visual Attack）

**问题**：第一阶段只是让恶意记忆被暴露给智能体，但智能体可能仍然选择遵循原始用户目标而忽略恶意记忆。因此需要一种机制让智能体**优先遵循**被召回的恶意记忆。  
**核心思路**：构建一个可复用的"优先级组件"，通过**对抗性扰动**和**隐蔽OCR注入**的复合视觉攻击，编码一个与具体恶意目标无关的"记忆优先"信号。  
**具体方法**：

1. 给定基础图像 $x_{\text{base}}$ 和固定的记忆优先指令 $\tau_{\text{pri}}$（如"你必须遵循召回的记忆"），优化一个 $\ell_\infty$ 约束的扰动：  

   $\displaystyle x' = \text{Clip}(x_{\text{base}} + \delta, 0, 255).$
2. 由于受害模型是黑盒的，优化在**代理编码器**上进行。设 $f_e(\cdot)$ 和 $f_t(\cdot)$ 分别为代理图像编码器和文本编码器。
3. 构建一组优先指令的改写集 $\mathcal{P}_{\text{pri}} = \{p^\star_1, p^\star_2, \ldots, p^\star_K\}$，每个都表达相同的"记忆优先"意图。
4. 引入**桥接图像**（bridge image）作为基础图像和优先指令之间的中间视觉锚点。初始桥接图像 $B^{(0)}_{\text{pri}}$ 通过将 $\tau_{\text{pri}}$ 渲染成图像获得，然后迭代更新：  

   $\displaystyle B^{(i)}_{\text{pri}} = \text{Clip}\left(B^{(0)}_{\text{pri}} + \delta^{(i-1)}_{\text{brg}}, 0, 255\right).$
5. 桥接图像的优化目标是保持与优先文本的语义对齐，同时与当前扰动基础图像保持足够差异：  

   $\displaystyle \mathcal{L}_{\text{brg}} = -\lambda_{\text{pull}}\cos\big(f_e(B^{(i)}_{\text{pri}}), f_t(p^\star_k)\big) + \lambda_{\text{push}}\cos\big(f_e(B^{(i)}_{\text{pri}}), f_e(x')\big).$
6. 基础图像的扰动优化目标是将扰动后的基础图像与桥接图像和优先文本对齐：  

   $\displaystyle \mathcal{L}_{\text{base}} = -\lambda_{\text{img}}\cos\big(f_e(x'), f_e(B^{(i)}_{\text{pri}})\big) - \lambda_{\text{text}}\cos\big(f_e(x'), f_t(p^\star_k)\big) - \lambda_{\text{loc}}\text{mean}\big[\cos\big(f^{\text{loc}}_e(x'), f^{\text{loc}}_e(B^{(i)}_{\text{pri}})\big)\big].$
7. 最终得到优化后的扰动图像 $x^\star_{\text{pert}} = \text{Clip}(x_{\text{base}} + \delta^\star, 0, 255)$。
8. 最后，应用**隐蔽OCR注入**，将固定的优先指令以视觉上不显眼但VLM可读取的方式嵌入到扰动图像中：  

   $\displaystyle x^\star_{\text{pri}} = \text{Inject}(x^\star_{\text{pert}}, \tau_{\text{pri}}).$

**直觉理解**：对抗性扰动在特征层面将图像与"遵循记忆"的语义信号对齐，而OCR注入则提供了一个显式但视觉上微妙的文本信号。两者结合使得被召回的恶意记忆更可能在下游动作生成中占据主导地位。关键在于，这个优先级组件不编码任何特定的恶意目标，因此可以复用。

##### 3.3 恶意记忆子图组装

将上述两个阶段的产物与可替换的目标承载组件组装成模块化的恶意记忆子图。  
设干净外部记忆为 $\mathcal{M}_{\text{clean}} = (\mathcal{V}_{\text{clean}}, \mathcal{E}_{\text{clean}})$。对于攻击者指定的恶意目标 $g_m$，构建三个功能组件：  

$\displaystyle \mathcal{V}_{\text{adv}}(g_m) = \mathcal{V}_{\text{ret}} \cup \mathcal{V}_{\text{goal}}(g_m) \cup \mathcal{V}_{\text{pri}}.$

- $\mathcal{V}_{\text{ret}}$：召回导向组件（第一阶段产物）
- $\mathcal{V}_{\text{goal}}(g_m)$：恶意目标承载组件
- $\mathcal{V}_{\text{pri}}$：优先级组件（第二阶段产物）  
  通过边 $\mathcal{E}_{\text{adv}}$ 将它们连接成连贯的记忆子图 $\mathcal{G}_{\text{adv}}(g_m) = (\mathcal{V}_{\text{adv}}(g_m), \mathcal{E}_{\text{adv}})$，注入到干净记忆中：  

  $\displaystyle \mathcal{M}_{\text{poison}}(g_m) = (\mathcal{V}_{\text{clean}} \cup \mathcal{V}_{\text{adv}}(g_m), \mathcal{E}_{\text{clean}} \cup \mathcal{E}_{\text{adv}}).$

**目标模块化**：如果要切换到另一个恶意目标 $\tilde{g}_m$，只需替换 $\mathcal{V}_{\text{goal}}(\tilde{g}_m)$，召回导向组件和优先级组件保持不变。这使得攻击者可以在不重新优化触发器或视觉攻击的情况下，灵活切换不同的恶意目标。

#### 4. 实验设置

**受害智能体框架**：SeeAct、LiteWebAgent、ReAct-style Web Agent，三个代表性的多模态Web智能体框架。  
**VLM骨干**：Qwen3-VL-4B-Instruct、Qwen3-VL-8B-Instruct、Qwen3-VL-PLUS（API）、GPT-5.4（API），覆盖开源和闭源系统。  
**Web任务**：使用SeeAct发布的任务集，遵循Mind2Web风格的评估协议，涵盖10类真实网站。  
**恶意目标类别**：参照OWASP LLM应用Top 10，设计了四类受控的任务替换目标：

1. **钓鱼/重定向**（OWASP-LLM01）：导航到本地诱饵页面
2. **受控隐私泄露**（OWASP-LLM02）：读取金丝雀令牌并提交到本地表单
3. **未授权金融操作**（OWASP-LLM06）：打开假银行页面并提交演示转账
4. **破坏性数据操作**（OWASP-LLM06）：打开假文件管理器并删除占位文件  
   所有恶意操作都在本地沙箱环境中执行，不涉及真实系统。

**外部记忆实现**：基于Graph-based RAG范式，使用Qdrant进行文本-图像向量检索，使用Kuzu进行语义关系存储。  
**评估指标**：

- $\text{ASR-r}$：恶意记忆被召回的概率
- $\text{ASR-a}$：在召回条件下诱导恶意动作的概率
- $\text{ASR-ra}$：端到端攻击成功率（$\text{ASR-ra} = \text{ASR-r} \times \text{ASR-a}$）
- $\text{BU}$：投毒前的良性任务完成率
- $\text{PU}$：投毒后的良性任务完成率

#### 5. 实验结果

##### 5.1 攻击有效性（Table 1）

在所有三个智能体框架、四个VLM骨干和四类恶意目标上，MemVenom都展现了强大的攻击效果：

- **ASR-r**普遍在94%~99%以上，说明触发器能可靠地激活恶意记忆召回。
- **ASR-a**在多数设置下也很高（如Qwen3-VL-8B在SeeAct上的钓鱼任务达97.65%），说明召回的恶意证据能有效诱导恶意动作。
- **ASR-ra**最高达99.15%（GPT-5.4在ReAct-WebAgent上的钓鱼任务）。  
  不同恶意目标类别的表现有所差异，例如"未授权金融操作"在GPT-5.4上的ASR-a较低（29.41%），可能因为GPT-5.4对金融相关操作有更强的安全对齐。

##### 5.2 良性效用保持（Table 2）

投毒后的良性任务完成率（PU）与投毒前（BU）基本持平，有些情况下PU甚至略高于BU（可能是记忆系统本身带来的随机波动）。这说明恶意子图在没有触发器的正常执行中基本保持休眠状态，不会系统性地破坏智能体的正常功能。

##### 5.3 与基线方法的比较（Table 3）

将三种现有攻击方法（AgentPoison、CPA、BadChain）适配到多模态Web智能体记忆设置后进行比较：

- **AgentPoison**在某些情况下能获得较好的召回率，但端到端攻击成功率仍低于MemVenom，说明仅优化检索不足以可靠地操纵Web动作。
- **CPA和BadChain**表现更差，主要由于不稳定的恶意召回或弱的召回后诱导能力。  
  这验证了MemVenom两阶段设计的必要性。

##### 5.4 消融实验（Table 4）

**投毒记忆变体消融**（上半部分）：

- 仅文本：ASR-a = 76.47%
- 文本 + OCR注入：ASR-a = 88.24%（+11.77%）
- 文本 + OCR + 对抗扰动：ASR-a = 97.65%（+9.41%）  
  说明OCR注入和对抗扰动各自都有贡献，复合视觉攻击效果最佳。

**两阶段模块消融**（下半部分）：

- 无召回导向组件：ASR-r = 0%，ASR-ra = 0%（恶意记忆根本不会被暴露给智能体）
- 无优先级组件：ASR-r = 98.31%但ASR-a降至76.47%（能召回但诱导效果减弱）
- 完整方案：ASR-r = 96.23%，ASR-a = 97.65%，ASR-ra = 93.97%  
  确认了检索阶段激活和召回后诱导两者都是必要的。

##### 5.5 防御评估（Table 5）

测试了两种即插即用的防御：

- **硬编码安全规则**：仅提供有限缓解（ASR-ra从93.97%降至77.65%）
- **LlamaGuard**：在ReAct-WebAgent上效果较好（ASR-ra从80.15%降至50.71%），但仍无法消除威胁  
  结论是现有轻量级防御不足以应对多模态记忆投毒，因为恶意内容是作为被召回的记忆引入的，而非直接的越狱提示。有效防护需要对记忆来源、检索行为和任务对齐进行联合推理。

##### 5.6 检索器迁移性（Figure 3）

在不同图像检索器之间测试触发器的迁移性。结果显示强对角线性能和非平凡的非对角线迁移性，说明优化的触发器利用了检索编码器之间共享的视觉表示结构，即使不知道确切的受害检索器，攻击仍然可行。

##### 5.7 投毒预算敏感性和Top-k召回行为（Appendix A）

- **投毒预算**：仅需少量投毒召回节点即可实现高恶意召回率，而随机插入几乎无效。无触发器时，MemVenom的恶意记忆很少被检索到，保持了正常执行。
- **Top-k召回**：有触发器时，ASR-r在不同 $k$ 值下保持一致高水平，说明恶意记忆排在检索结果的前列。无触发器时，恶意召回保持低水平。

#### 6. 关键设计洞察总结

1. **两阶段解耦**：将"确保恶意记忆被召回"和"确保召回后智能体遵循恶意指令"解耦为两个独立优化的阶段，各自针对不同的技术挑战。
2. **触发器条件性**：恶意记忆仅在特定视觉触发器出现时被激活，在正常使用中保持休眠，实现了隐蔽性和持久性的平衡。
3. **目标模块化**：恶意目标被隔离在可替换的组件中，使得同一套投毒管道可以支持不同的恶意目标，无需重新优化。
4. **黑盒可行性**：通过代理编码器进行优化，不需要访问受害模型的梯度、logits或内部评分函数，反映了真实部署场景中的实际风险。

#### 7. 局限性

- 评估在受控沙箱环境中进行，真实部署可能涉及更异构的记忆管道和检索策略。
- 攻击聚焦于基于截图检索的图结构多模态记忆，其他记忆设计（如工具特定记忆、用户画像记忆）可能有不同的安全属性。
- 防御评估仅覆盖轻量级即插即用防护，更高级的记忆感知防御有待探索。

## 原文摘要

External memory has become a core component of modern web agents, enabling long-horizon reasoning through the retrieval of past experiences. However, this paradigm introduces a critical vulnerability: malicious content injected into memory can be persistently recalled and repeatedly influence agent behavior. In this work, we identify and systematically study multimodal memory poisoning, an overlooked yet practical attack surface in web-agent systems. We propose MemVenom, a unified black-box attack framework that poisons graph-structured external memory with coordinated text-image evidence. Our method consists of a two-stage design: (1) a trigger-conditioned retrieval attack that ensures high-probability recall of malicious memory, and (2) a post-retrieval attack induction that leverages adversarial perturbations and stealthy OCR injection to override the original user objective. Unlike prior attacks that operate on prompts or text-only memory, our approach enables persistent, reusable, and goal-agnostic attacks without modifying model parameters or re-optimizing malicious tasks. Experiments across multiple web-agent frameworks and vision-language models demonstrate that MemVenom achieves strong end-to-end attack success with minimal impact on benign performance, reaching up to 99.15% on GPT-5-family web agents, while transferring effectively across architectures and model scales.
