# MemLeak: Diagnosing Information Leaks in Multimodal Agent Memory

Wang, Kuan, Zhang, Chao · 2026

[论文原文](https://arxiv.org/abs/2606.29788)

## 核心机制

检查删除事实从保留文本/图像中的恢复，比较内容感知删除

## 适用范围与局限

特定政策下行为残留，不是遗忘不可能性定理

## 详细解读

**核心总结：**

这篇论文揭示了多模态AI智能体的记忆系统在执行"遗忘"操作时存在严重的信息泄露问题。当系统删除某个事实的文本记录后，该信息仍可通过保留的图像（包括标记给完全不同事实的图像）被恢复，因为视觉-语言模型（VLM）在推理时会利用隐式视觉线索。研究提出了信息溯源图（IPG）分类体系和MemLeak基准测试，发现通过保留的相关文本可恢复18.3%的已删除信息，通过图像可恢复12.0%（其中47%的图像泄露无法通过文本恢复），而内容感知的语义删除可将图像残留降至2.0%。

---

### 研究背景与动机

随着多模态AI智能体的发展，这些系统需要维护包含文本和图像的长期记忆。用户可能出于隐私、安全或法规遵从（如GDPR的"被遗忘权"）要求系统删除特定信息。当前的记忆系统通常采用简单的做法：删除对应的文本条目，然后报告删除成功。

然而，论文发现这种删除方式存在根本性缺陷。在多模态环境中，信息不仅存储在显式的文本中，还隐含在视觉内容里。即使文本被删除，视觉-语言模型仍可能从保留的图像中提取出相关信息，造成**信息泄露**。

### 核心概念：信息溯源图（IPG）

论文提出了**信息溯源图（Information Provenance Graph, IPG）**作为理论框架，用于分类记忆系统中不同类型的信息表征及其删除能力。

IPG将记忆表征按照**删除可行性（deletion affordance）**进行分类：

1. **直接可删除的表征**：如显式存储的文本记忆条目，可以通过标准的数据库删除操作移除
2. **间接关联的表征**：包括：
   - **相关文本**：其他记忆条目中提到相关信息的文本
   - **视觉内容**：包含相关信息视觉线索的图像，即使这些图像被标记给其他事实

IPG揭示了删除失败的多个渠道，形成了一个**删除级联（deletion cascade）**：即使删除了直接记忆，信息仍可能通过其他渠道泄露。

### MemLeak基准测试

#### 测试设计

MemLeak是一个系统性的基准测试，用于量化多模态记忆系统中的信息泄露程度。测试采用三层探测方式：

1. **直接探测**：测试已删除文本条目的直接可访问性（在具有删除能力的系统中）
2. **文本残留探测**：测试是否可以通过保留的相关文本条目恢复已删除的信息
3. **图像残留探测**：测试是否可以通过保留的图像恢复已删除的信息

#### 关键发现

实验结果揭示了令人担忧的信息泄露程度：

- **直接探测**：成功率<1%，说明文本删除本身是有效的
- **相关文本泄露**：18.3%的已删除信息可通过保留的相关文本恢复
- **图像泄露**：12.0%的已删除信息可通过保留的图像恢复
  - 基准盲测准确率：0.0%（说明不是随机猜测）
  - 假阳性率（FPR）：0.3%（说明判断的可靠性）

**最关键的发现**：47%的图像泄露无法通过文本恢复，这意味着图像提供了独立的信息泄露渠道，而非仅仅是文本信息的重复。

#### 视觉线索的隐式性

论文强调，这些图像可能被标记给**完全不同的事实**。例如：

- 用户可能有一张在某餐厅拍摄的照片，图像元数据标记为"周末聚会"
- 如果用户要求删除"我去过这家餐厅"的事实
- 即使删除了相关文本，VLM仍可能从照片背景中的餐厅招牌、菜单等视觉线索推断出这一信息

这说明VLM在推理时会利用**隐式视觉线索（implicit visual cues）**，而不仅仅依赖显式的文本标注。

### 缓解方案：内容感知语义删除

论文提出了**内容感知语义删除（content-aware semantic deletion）**作为缓解策略。这种方法不仅删除显式的文本记录，还会：

1. 识别可能包含相关视觉信息的图像
2. 评估图像内容与待删除事实的语义关联
3. 删除或脱敏相关图像

实验显示，采用内容感知语义删除后，图像残留率从12.0%降至**2.0%**，显著提升了删除的有效性。

剩余的2.0%残留可能来自：

- VLM的推理能力限制
- 极其微妙的视觉线索
- 方法本身的不完善

### 实验的鲁棒性验证

论文通过多个维度验证了发现的普遍性和可靠性：

#### 1. 跨模型验证

测试了多个不同的视觉-语言模型，证明信息泄露不是特定模型的问题，而是多模态记忆系统的系统性风险。

#### 2. 生产系统验证

在实际的生产级记忆系统中重现了泄露现象，说明这不仅是理论问题，而是现实威胁。

#### 3. 真实图像验证

使用了来自Unsplash的真实授权照片（而非合成数据），确保发现适用于真实世界场景。

#### 4. 人工验证

采用双标注者（dual-annotator）人工验证，Cohen's Kappa系数达到**0.88**，表明评判标准具有高度可靠性（Kappa > 0.8通常被认为是"几乎完全一致"）。

### 研究意义

#### 理论贡献

1. **首次系统性研究**多模态记忆系统的删除问题
2. 提出IPG框架，为分析信息表征和删除能力提供了理论工具
3. 揭示了视觉信息作为独立泄露渠道的重要性

#### 实践影响

1. **隐私风险警示**：当前多模态AI系统的删除机制存在重大缺陷
2. **合规性挑战**：简单的文本删除不足以满足数据保护法规要求
3. **系统设计指导**：需要考虑多模态信息的语义关联进行删除

#### 方法论贡献

MemLeak基准测试提供了标准化的评估框架，可用于：

- 测试现有系统的删除有效性
- 评估新删除算法的性能
- 比较不同缓解策略的效果

### 未来研究方向

虽然论文没有明确列出，但从研究内容可以推断几个重要方向：

1. **更强的语义删除算法**：如何更准确地识别所有相关的多模态内容？
2. **删除的可验证性**：如何向用户证明信息确实被彻底删除？
3. **删除与功能的权衡**：完全删除可能影响系统功能，如何平衡？
4. **跨模态的信息追踪**：如何在多模态数据中追踪信息流？
5. **其他模态的泄露**：音频、视频等其他模态是否存在类似问题？

这项研究为多模态AI系统的隐私保护和数据管理开辟了重要的研究方向，对构建可信的AI智能体具有重要意义。

## 原文摘要

When a multimodal AI agent is asked to forget a fact, current memory systems usually delete the text entry and report success. We find that the fact can remain recoverable from retained user images, including images tagged to entirely different facts, because VLMs use implicit visual cues at inference time. We introduce the Information Provenance Graph (IPG), a taxonomy that classifies memory representations by deletion affordance. The IPG reveals that deletion fails through multiple channels. Our benchmark, MemLeak, measures this across a deletion cascade: direct probing of deletion-capable systems yields <1%, but retained correlated text enables 18.3% recovery, and retained images enable 12.0% recovery (0.0% blind baseline, 0.3% FPR) -- with 47% of image leaks not text-recoverable. Content-aware semantic deletion reduces the image residual to 2.0%. The residual appears across multiple VLMs, a production memory system, and real Unsplash-licensed photographs. Dual-annotator human validation (kappa = 0.88) confirms judge reliability.
