# GraphMemix: Query-Aware Evidence Forests for Long-Term Multimodal Agent Memory

Li, Geng, Wang, Yuhao, Li, Dong, Hao, Jianye, Peng, Yuxin · 2026

[论文原文](https://arxiv.org/abs/2608.26983)

## 核心机制

查询相关图扩展与预算下的证据森林选择

## 适用范围与局限

包括验证和组织成本；不将其直接当持续自进化

## 详细解读

### 论文核心总结

GraphMemix 提出了一种面向多模态智能体长期记忆的**查询感知证据森林（query-aware evidence forest）**框架。其核心思想是：不在问题到来之前对全部历史记忆做昂贵的离线摘要或压缩，也不仅仅依赖嵌入相似度做简单匹配，而是在用户提问之后，将记忆选择建模为一个**组合优化问题**——在一个有界的候选图上，联合选择节点（记忆）和边（记忆间的关系），构建一棵最大权重的证据森林。该框架通过三个阶段实现：（1）候选图构建，从多视角检索种子出发，沿结构关系和语义关系扩展出查询相关的子图；（2）证据效用与激活代价估计，分别用节点验证器评估单条记忆的直接支持度、用证据链验证器（ECV）评估记忆相对于锚点的增量互补价值，从而抑制冗余和冲突；（3）森林优化，在最大证据预算约束下，用 Kruskal 算法精确求解最大权重生成森林，自适应地决定选多少条、选哪些记忆以及保留哪些关系。在四个长期多模态记忆基准上，GraphMemix 以 Qwen3-VL 为阅读器时将四数据集宏平均 Judge Accuracy 从最强基线的 49.80% 提升到 61.55%，同时在准确率-生命周期成本的帕累托前沿上优于所有对比方法。

### 一、研究背景与动机

#### 1.1 问题场景

基于大型视觉-语言模型（LVLM）的个人助理智能体需要维护**长期多模态记忆**：不仅包括历史对话，还包括照片、邮件、聊天记录、工作文档等持续更新的异构数据。当用户提出一个问题时，系统需要从海量记忆中检索出精确的、与查询相关的上下文，送入阅读器生成答案。

#### 1.2 现有方法的两条路线及其不足

**路线一：问题无关的离线摘要/结构化记忆。** 代表工作包括 MIRIX（将经历分为情景记忆、语义记忆、程序记忆和知识库）、SGM（将不同来源的内容映射为统一的结构化记录）、A-MEM（构建结构化笔记并维护链接）、M²A 等。这些方法在问题到来之前就对全部历史做压缩处理，构建通用表示。问题在于：

- **冷启动和持续更新代价大**：因为不知道未来会问什么问题，所以默认处理全部历史以避免遗漏。
- **信息丢失**：问题无关的压缩可能丢弃后来被证明关键的视觉属性、状态变化或局部上下文。

**路线二：多模态 RAG（检索增强生成）。** 代表工作包括 MuRAG（直接从图文语料库检索）和 Pensieve（结合图像描述、OCR、时空元数据和多模态相似度搜索个人视觉经历）。这些方法保留了原始视觉访问且处理代价低，但问题在于：

- **过度选择近似重复**：基于相似度排序容易选中大量近似重复的记忆。
- **遗漏互补证据**：与查询表面不相似但实际上在与其他记忆组合时才体现价值的记忆会被遗漏。先前工作表明，回答一个问题往往需要多条互补记忆，而语义相似度本身无法衡量它们的联合证据价值。

#### 1.3 GraphMemix 的核心思路

GraphMemix 的关键洞察是：**记忆选择不应该是逐条独立打分，而应该是一个集合级别的结构化优化问题。** 它在问题到来后，从大规模记忆档案中重建必要的证据森林。节点捕捉单条记忆的直接效用，边捕捉一条记忆在以另一条记忆为锚点时的增量价值。通过联合优化节点和边，系统可以：

- 恢复与查询表面不相似但通过关系链可达的互补证据
- 抑制冗余和冲突信息
- 避免对全部历史做生成式预处理的开销

### 二、方法详解

#### 2.1 问题形式化

设 $\mathcal{V} = \{e_i\}_{i=1}^N$ 为用户的多模态记忆档案，包含 $N$ 条历史记录。$q = (q^{\text{text}}, q^{\text{vis}})$ 为一个可能带有视觉输入的问题。每条记忆 $e_i$ 可能包含文本、图像、视频及其衍生表示。  
一个**证据选择器** $\Pi$ 选择至多 $K$ 条记录并组织为有序序列 $O_q$，然后一个冻结的多模态生成器 $\mathcal{M}$ 生成答案：  

$\displaystyle (S_q, O_q) = \Pi(q, \mathcal{V}; K), \quad S_q \subseteq \mathcal{V}, \quad |S_q| \le K,$

  

$\displaystyle \hat{y} = \mathcal{M}(q, O_q).$

  
目标是设计 $\Pi$，使选出的证据提供完整上下文以提高 $\hat{y}$ 的正确性。

#### 2.2 查询条件化的证据森林目标

如果简单地按查询-记忆相似度独立排序，会浪费名额在重复项上，并遗漏措辞不同但实际关键的后续状态、回复或引用上下文。反过来，如果把所有相连记录都塞进去，又会引入无关上下文。  
GraphMemix 将候选记忆表示为**节点**，将可能的上下文依赖关系表示为**边**。对于选中的节点集 $S$ 和无环边集 $F$，选择目标为：  

$\displaystyle \max_{S, F} \; \mathcal{U}_{\text{node}}(S \mid q) - \mathcal{C}_{\text{edge}}(F \mid q) - \mathcal{C}_{\text{open}}(S, F)$

  
其中：

- $\mathcal{U}_{\text{node}}$：直接证据效用，衡量选中记忆对问题的直接支持
- $\mathcal{C}_{\text{edge}}$：关系扩展的不确定性代价
- $\mathcal{C}_{\text{open}}$：开启独立证据链的代价（森林中连通分量的数量惩罚）

#### 2.3 候选图构建（Stage 1）

这一步的目标是从海量记忆中快速筛选出一个有界的、与查询相关的候选子图。  
**多视角检索。** 同一条记忆可以通过不同信号被检索到：原始图像（物体和场景）、描述文本（事件和动作）、OCR（印刷文字）、视频帧（视觉状态）。设 $\mathcal{U}_i$ 为记忆 $e_i$ 的检索视角集合，其初始得分为：  

$\displaystyle s_i(q) = \max_{u \in \mathcal{U}_i} \text{sim}(h(q), h(u))$

  
其中 $h$ 是共享的多模态编码器。使用 max pooling 意味着只要有一个视角匹配上就能进入候选集，提供了多条进入候选集的路径。  
**查询相关子图发现。** 使用两类互补的关系来源：

1. **Schema 关系**：编码可观察的交互结构，如来自同一会话或同一地点的记录。定义为：  

   $\displaystyle E_{\text{schema}} = \{(i,j) : \exists r \in \mathcal{T}_{\text{schema}}, \; \phi_r(e_i, e_j) = 1\}$
2. **语义关系**：连接具有相互相似表示的记忆，使用互 $k$-近邻（mutual KNN）：  

   $\displaystyle E_{\text{sem}} = \{(i,j) : i \in \mathcal{N}_k(j), \; j \in \mathcal{N}_k(i)\}$

     
   将两类边合并得到发现图 $G^{\text{disc}} = (\mathcal{V}, E_{\text{schema}} \cup E_{\text{sem}})$。从多视角检索的 top-$L$ 种子记忆 $R_q^{(L)}$ 出发，收集 $H$ 跳内可达的节点，保留至多 $M$ 个候选：  

   $\displaystyle \widetilde{C}_q = R_q^{(L)} \cup N_{\le H}^{G^{\text{disc}}}(R_q^{(L)}), \quad C_q = \text{Top}_M(\widetilde{C}_q)$

     
   排序结合了检索顺序和关系扩展顺序。这一步保留了局部上下文，同时限定了后续所有语义推理的规模。  
   实际参数设置：$L=24$ 个种子，$H=1$ 跳扩展，互 $k$-NN 中 $k=8$，保留 $M=48$ 个候选，最大阅读器预算 $K=10$。

#### 2.4 证据效用与激活代价（Stage 2）

这一阶段为候选图中的每个节点和每条边赋予查询条件化的分数。

##### 2.4.1 直接节点效用

检索相似度是稳定的全局先验，但对否定、时间变化、视觉引用等情况不够。论文引入一个**列表式节点验证器**（listwise node verifier），它一次性读入查询 $q$ 和全部候选 $C_q$，输出每条记忆 $e_i$ 独立支持问题的程度 $v_i(q)$。列表式输入使候选在同一语义尺度上比较。  
将归一化的验证器分数 $\tilde{v}_i$ 与检索分数融合：  

$\displaystyle p_i(q) = \sigma(\tau[\alpha s_i(q) + (1-\alpha)\tilde{v}_i(q) - \delta])$

  

$\displaystyle \mathcal{U}_{\text{node}}(S \mid q) = \sum_{i \in S} p_i(q)$

  
其中 $\alpha$ 平衡检索先验和条件判断，$\tau$ 和 $\delta$ 控制尺度和偏移。实际使用 $(\alpha, \tau, \delta) = (0.8, 5.2, 0.7)$，验证器返回 $v_i(q) \in [0,5]$，$\tilde{v}_i(q) = v_i(q)/5$。

##### 2.4.2 锚点条件化的关系验证（Evidence-Chain Verifier, ECV）

节点验证只能判断一条记忆单独是否有用，但**无法区分冗余和互补**。例如，两条记忆可能都与查询相关，但内容几乎完全重复；或者一条记忆只有在已知另一条记忆的前提下才提供增量信息。  
GraphMemix 从初始检索中取出一个高置信度的**锚点集** $A_q$，只检查锚点与候选之间的 schema 边：  

$\displaystyle E_q^{\text{elig}} = \{(a, i) \in E_{\text{schema}} : a \in A_q, \; i \in C_q\}$

  
**ECV** 在一次列表式调用中读入这些配对。对每个候选，它：

1. 选择最能解释该候选增量角色的锚点
2. 预测一个增量支持分数 $s_{ai}^{\text{inc}}(q)$
3. 分配六种角色之一：`new_fact`（新事实）、`clarification`（澄清）、`corroboration`（佐证）、`redundant`（冗余）、`conflict`（冲突）、`irrelevant`（无关）  
   只有得分为正且角色为前三种（new_fact、clarification、corroboration）的最佳锚点边才被保留，形成信任图：  

   $\displaystyle G_q^{\text{trust}} = (C_q, E_q^{\text{trust}}), \quad E_q^{\text{trust}} \subseteq E_q^{\text{elig}}$

     
   对于保留的边 $(a, i)$，其可靠性和不确定性代价为：  

   $\displaystyle w_{ai}(q) = w_{ai}^{\text{schema}} \frac{s_{ai}^{\text{inc}}(q)}{s_{\max}}, \quad c_{ai}(q) = -\log w_{ai}(q)$

     
   其中 $w_{ai}^{\text{schema}}$ 是 schema 特定的可靠性上限（设为 0.99）。边代价为：$\mathcal{C}_{\text{edge}}(F \mid q) = \lambda \sum_{e \in F} c_e(q)$。  
   角色门控决定一条边是否携带正向增量语义，连续分数控制其信用。因此，相关但冗余或冲突的记忆不会获得结构性奖励。

##### 2.4.3 独立链代价

设 $m(S, F)$ 为森林 $(S, F)$ 中连通分量的数量。每个分量是一条独立解释的证据链，定义：  

$\displaystyle \mathcal{C}_{\text{open}}(S, F) = \kappa \, m(S, F)$

  
$\kappa \ge 0$ 平衡独立证据与对已有事件的上下文补全。

#### 2.5 森林优化（Stage 3）

将上述各项代入目标函数，得到完整的优化问题：  

$\displaystyle (S_q^\star, F_q^\star) = \arg\max_{S, F} \sum_{i \in S} p_i(q) - \lambda \sum_{e \in F} c_e(q) - \kappa m(S, F)$

  

$\displaystyle \text{s.t.} \quad S \subseteq C_q, \; |S| \le K, \; F \subseteq E_q^{\text{trust}}[S]$

  
由于边代价非负，从任何环中移除一条边不会降低目标值，因此最优的 $F$ 可以选为**森林**（无环连通子图的集合）。此时 $m(S, F) = |S| - |F|$。  
定义**结构增益** $B_e(q) = \kappa - \lambda c_e(q)$，目标可等价写为：  

$\displaystyle \sum_{i \in S} (p_i(q) - \kappa) + \sum_{e \in F} B_e(q)$

  
这个形式有非常直观的解释：

- **孤立记忆**贡献 $p_i - \kappa$，只有当其效用足以证明开启一条独立证据链时才被保留
- **通过边加入已有分量的记忆**，其边连接恢复了一个开启代价，边际贡献变为 $p_i - \lambda c_e$
- 因此，可信的互补证据受到保护，而低效用的孤立证据会被移除

##### 2.5.1 有界精确基数细化

在所有 $M$ 个候选上的联合优化是组合问题。论文使用**确定性两阶段求解器**：  
**第一阶段：固定基数的森林提案。** 产生一个 $K$ 节点的提案 $\bar{S}_q \subseteq C_q$：

- 从 top-$K$ 节点效用初始化
- 每次评估一个选中-未选中的交换
- 对每个提议的节点集用 **Kruskal 算法**精确重算最大权重森林
- 在确定性 1-swap 局部最优处终止

**第二阶段：变基数精确求解。** 在冻结的提案内精确求解：  

$\displaystyle F_S^\star = \arg\max_{F \subseteq E_q^{\text{trust}}[S]} \sum_{e \in F} B_e(q)$

  

$\displaystyle (S_q^\star, F_q^\star) = \arg\max_{\emptyset \ne S \subseteq \bar{S}_q} \left[\sum_{i \in S}(p_i(q) - \kappa) + \sum_{e \in F_S^\star} B_e(q)\right]$

  
对每个子集，Kruskal 应用于正增益边精确给出 $F_S^\star$。平局时优先选择更少的记忆和更早的提案排名。返回的解在 $\bar{S}_q$ 的所有非空子集上全局最优。

##### 2.5.2 证据序列化

### 选出的森林被序列化为有序序列送入阅读器：每个连通分量中效用最高的节点作为根，按根效用排序各分量，每个分量内广度优先遍历。这样阅读器先看到直接锚点，再看到通过可信关系恢复的上下文证据。

### 三、实验

#### 3.1 实验设置

**数据集：** 四个代表性的个人多模态记忆基准：

- **ATM-Bench**：一个长个人档案，包含 6,742 封邮件、3,759 张图片、533 个视频，1,044 个问题
- **Mem-Gallery**：20 个角色驱动的对话上下文，240 个会话，7,944 条记忆，1,711 个问题
- **MemEye**：16 个模式特定上下文，3,392 条记忆，1,855 个问题，侧重细粒度视觉记忆
- **H2HMem**：25 个完整的多方对话上下文，7,078 条记忆，1,982 个问题

**评估指标：** 主要使用 LLM-as-a-Judge 协议（GPT-5-mini 作为评判者），报告 Judge Accuracy。每个基准还报告一个原生指标（EM、MCQ EM、Recall 等）。  
**基线：** A-MEM、UniversalRAG、MemGuide、LightMem、VimRAG。所有方法使用相同的阅读器。  
**编码器：** 冻结的 gme-Qwen2-VL-2B-Instruct，产生 1,536 维多模态嵌入。

#### 3.2 主要结果

**Qwen3-VL-8B-Instruct 作为阅读器（Table 1）：**  
GraphMemix 在所有四个基准上的 Judge Accuracy 都超过最强公开基线。四数据集宏平均达到 **61.55%**，比最强方法 UniversalRAG 的 49.80% 高出 **11.75 个百分点**。在各原生指标上也全面领先。  
**Gemma 4 12B Unified 作为阅读器（Table 2）：**  
GraphMemix 宏平均 Judge Accuracy 达到 **67.42%**，比 UniversalRAG 的 55.09% 高出 **12.33 个百分点**。增益跨越不同基础模型和异构记忆基准。

#### 3.3 效率分析

论文比较了完整生命周期成本：消化全部历史一次 + 回答所有问题一次。  
在 ATM-Bench 上（Figure 3），GraphMemix 在获得最高准确率的同时，完整生命周期分别比 A-MEM、VimRAG、LightMem 快约 1.78×、4.27×、4.74×。它位于经验时间-准确率的**帕累托前沿**上：没有对比系统能在更短的生命周期内匹配其准确率。  
在其余三个基准上（Figure 5）也展现了一致的趋势，GraphMemix 在所有四个基准上都位于帕累托前沿。

#### 3.4 消融实验

**增量效果分析（Table 3）：**  
从嵌入 top-$K$（49.20%）出发，逐步添加：

1. 多视角检索 → 53.60%（+4.40）
2. 节点验证器 → 58.80%（+5.20）
3. ECV 重排序（将 ECV 信息作为逐点奖励）→ 59.70%（+0.90）
4. 森林优化（完整 GraphMemix）→ **61.55%**（+1.85）  
   最后一步的提升隔离了将证据作为结构化集合选择（而非仅将关系分数加到个别候选上）的收益。

**恢复低排名关系证据（Table 4 & 5）：**  
Table 4 将金标证据分为三类：

- **Direct**：已在 source top-10 中
- **Recoverable**：不在 top-10 但在关系扩展后的候选图中
- **No Access**：两者都不满足  
  所有四个数据集都包含被 top-10 遗漏但可通过候选图暴露的金标证据。Table 5 显示 GraphMemix 实际上为 40.08%–68.48% 的可恢复问题至少恢复了一条金标记忆。

**优化行为（Figure 2）：**  
在全部 6,592 个评估问题上，外层 1-swap 搜索在前几步接受的更新中产生了大部分目标改进，6 步后变化可忽略。这表明有界提案通常只需少量交换即可修正。  
**ECV 的效果（Table 6）：**  
与固定边（每条 schema 边赋予相同的查询无关可靠性 0.99）相比，ECV 在所有四个数据集上提高了 Hit@10，同时将选中的边数从约 6-7 条减少到 0.25-1.47 条。它抑制了通过整个轮次或会话的无条件传播。  
**两个验证器分离职责（Table 7）：**  
将节点验证和 ECV 分为两次调用（而非合并为一次调用），宏平均 Accuracy 和 Recall@10 分别提高了 2.00 和 3.00 个点。两个验证器没有串行依赖，可以并行执行。

#### 3.5 受控证据集选择实验（Table 9 & 10）

为了隔离森林优化的贡献，论文冻结了所有前置步骤（相同的 48 个候选、校准的节点效用、ECV 输出），只比较不同的选择策略，每个都返回恰好 $K=10$ 条记忆。  
结果显示：

- 通用多样性/覆盖方法（MMR、Rel.-Red.、DPP、Facility Location）**没有**比纯节点效用 top-$K$ 更好
- 使用验证关系作为逐点奖励提升到 57.26
- 联合森林选择器达到 **57.74**  
  在净金标恢复量（Table 10）上，通用多样性方法的净恢复为负（即它们在恢复一些低排名金标的同时丢弃了已有的金标），而森林提案恢复了 +43 条净金标记忆，特别是在 H2HMem 上恢复了 +31 条。

#### 3.6 定性分析

Figure 4 展示了一个 Mem-Gallery 的例子：问题是"对话中哪两只狗被描述为聪明且学习快？"。独立排序只检索到部分答案相关的历史。GraphMemix 执行了 5 次改进性 1-swap，用配对的对话轮次替换了孤立的对话轮次，将每只狗的身份和品种与其描述的学习行为连接起来。目标从 1.340 提升到 2.133，金标覆盖从 3/4 提升到 4/4。最终证据同时支持了 Lumi（马尔济斯犬）和 Coco（玩具贵宾犬），得到完整的双实体答案。而 A-MEM 只回答了"Lumi 和马尔济斯犬"，MemGuide 回答了"玩具贵宾犬和标准贵宾犬"，都不完整。

### 四、关键设计要点总结

1. **查询时构建而非离线预处理**：避免了对全部历史做生成式预处理的巨大开销，同时避免了问题无关压缩导致的信息丢失。
2. **多视角检索 + 关系扩展**：通过图像、描述、OCR 等多视角提供多条进入候选集的路径，再通过 schema 和语义关系扩展暴露局部上下文。
3. **节点效用与边效用的解耦**：节点验证器评估单条记忆的直接支持，ECV 评估条件化的增量互补价值，两者职责分离、并行执行。
4. **角色门控机制**：ECV 的六种角色分类（new_fact、clarification、corroboration、redundant、conflict、irrelevant）确保只有真正提供增量信息的关系被保留。
5. **森林结构的自适应基数**：通过连通分量代价 $\kappa$，系统自动决定选多少条记忆——孤立记忆需要足够高的效用才能被保留，而通过可信边连接到已有分量的记忆门槛更低。
6. **精确求解**：对于任何固定节点集，Kruskal 算法精确求解最大权重森林；变基数阶段在冻结提案内精确枚举所有子集。

## 原文摘要

Organizing long-term memory for multimodal agents remains challenging because existing methods either suffer from expensive question-agnostic offline summaries or naive embedding similarity matching that introduces incomplete and redundant context. To address these issues, we propose GraphMemix, a combinatorial-optimization graph memory framework that models memory organization as query-aware evidence-forest construction. Specifically, our method consists of three key components:(1) candidate graph construction, which expands multi-view seed memories through schema and semantic relations to acquire query-aware original context; (2) evidence utility and activation costs, which decouples direct memory support from anchor-conditioned relation verification to suppress redundant or conflicting information; and (3) forest optimization, which jointly selects a forest-format memory context under a maximum evidence budget and its reliable relational structure. By organizing memory into a query-relevant subgraph, the method avoids substantial lifecycle cost and recovers low-similarity complementary evidence. Experimental results across four long-term multimodal memory benchmarks demonstrate significant improvements with different foundation models and establish a new Pareto frontier between accuracy and lifecycle cost.
